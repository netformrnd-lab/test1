# 블로그 원고 작성

결과물은 **네이버 블로그 에디터에 그대로 붙여넣는 HTML** 입니다.

## 1단계 — 기준부터 읽는다 (건너뛰지 말 것)

| 파일 | 무엇을 |
|---|---|
| `브랜드기준/01-브랜드-원메시지.md` | 브랜드 원메시지, **쓸 수 있는 수치 목록**, 실적, 연락처 |
| `브랜드기준/02-톤앤매너.md` | **브랜드별 금지어·자동 교정표**, 문장 스타일 |
| `브랜드기준/03-페르소나.md` | 누구에게 말하는가 (브랜드마다 페르소나가 다릅니다) |
| `브랜드기준/08-블로그-서식.md` | **글 구조 + HTML 블록 원본** ← 여기 서식을 그대로 씁니다 |
| `브랜드기준/04-고객여정맵.md` | 이 글이 어느 단계용인가 |
| `브랜드기준/06-키워드맵.md` | 이미 잡아둔 키워드 |
| `콘텐츠/블로그/` 최근 3~5개 | **중복 방지** |

## 2단계 — 필요한 것만 묻는다 (최대 3개)

사용자가 이미 준 정보는 다시 묻지 않습니다.

| 항목 | 없으면 |
|---|---|
| **브랜드** | 물어봅니다. `POUR공법` / `POUR솔루션` / `아파트스퀘어` / `넷폼` |
| **글 종류** | 키워드에서 추론 — `일반 글` / `뉴스·소식` (수상·인증·행사 등) |
| **키워드/주제** | 물어봅니다 |
| 페르소나 | 브랜드에 맞는 것을 골라 쓰고 **"김영수 회장(입대의) 기준으로 잡았습니다"** 라고 알립니다 |
| 여정 단계 | 주제에서 추론하고 알립니다 |

**뉴스·소식일 때는 사실을 반드시 확인합니다.** 정확한 명칭·날짜·수치를 모르면
`[확인 필요: 항목]` 으로 비우고 사용자에게 알립니다. **추측 금지.**

## 3단계 — 서식대로 쓴다

`08-블로그-서식.md` 에서 **해당 브랜드·글종류의 구조와 HTML 블록을 그대로** 가져옵니다.

- POUR공법 일반 글 → `1. POUR공법 블로그` 섹션
- POUR공법 뉴스 → `2. POUR공법 뉴스·소식` 섹션
- 아파트스퀘어 → `3. 아파트스퀘어 블로그` 섹션 (**문단 가운데 정렬**, 화자는 건축사 조현식)

### 문장 스타일 (모든 브랜드 공통)
1. **한 문장 = 최대 한 줄 (15~20자)**
2. **2~3문장마다 `<br><br>`**
3. 각 단락 3~4줄 이내
4. 독자에게 말 걸듯

### 검색에 걸리게 (SEO / AEO / GEO)
- 제목 앞쪽에 핵심 키워드, 첫 100자 안에 한 번, 본문 3~5회 (억지 반복 ❌)
- 소제목 중 2개 이상을 **질문 형태**로, 바로 아래 **첫 문장에서 40자 이내 직답**
- **"작년"❌ → "2025년"✅** 연도·수치·고유명사를 문장 안에 명시
- 표 또는 번호 목록 최소 1개 (AI가 인용하기 쉬운 형태)

### 🚨 사실 규칙
- `01-브랜드-원메시지.md` 의 **실적 표에 있는 수치만** 사용합니다.
- 표에 없는 수치·인증·수상·순위·가격은 `[확인 필요: 항목명]` 으로 **비웁니다.**
- **절대 그럴듯한 숫자를 지어내지 마세요.**
- 대형 단지 실명(헬리오시티 등)은 공개 동의가 확인된 경우만. 아니면 `[동의 확인 필요]`.

## 4단계 — 금지어를 직접 검사한다 (필수)

원고를 다 쓴 뒤, `02-톤앤매너.md` 의 **해당 브랜드 금지어·자동 교정표**를 한 줄씩 대조해
걸린 표현을 **대체 표현으로 바꿉니다.**

특히 자주 걸리는 것:
- POUR: `신기술` `혁신` `최초` `하자` `민원` `보장` `저렴`
- 아파트스퀘어: `보장` `감독` `안전 관리` `계획 수립` `조치를 취합니다` `열화상 카메라` `실적 건수`
- 아파트스퀘어 **확립된 현재형**: `이제부터/새롭게/최근/도입/개편/앞으로는` → 단정형 현재형으로
- 아파트스퀘어 **역할 경계**: "우리가 골라준다/결정한다/시공한다" → 검토·확인·진단·감리로

바꾼 것은 마지막 보고에 **"자동 교정한 표현"** 으로 목록화합니다.

**예외**: `국토교통부 건설신기술` 은 금지어 `신기술` 을 포함하지만 **공식 제도 명칭**이므로
그대로 씁니다. 이런 고유명사 예외는 교정하지 말고, 보고에 한 줄로 알립니다.

## 5단계 — 저장한다

`콘텐츠/블로그/YYYY-MM-DD-브랜드-키워드/` 폴더를 만들고 **파일 3개**를 저장합니다.

**① `본문.html`** — 복사용. HTML 조각만 넣습니다.
`<!DOCTYPE>` `<html>` `<head>` `<body>` 같은 뼈대 태그와 코드블록 표시(```)는 **넣지 않습니다.**
(브라우저로 열어서 미리보기도 됩니다)

**② `미리보기.html`** — 브라우저로 열어 확인하는 용도.
`본문.html` 내용을 아래 껍데기로 감쌉니다. **복사는 `본문.html` 에서 합니다.**
```html
<!DOCTYPE html><html lang="ko"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>미리보기 — [제목]</title>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700;900&display=swap" rel="stylesheet">
<style>
 body{margin:0;background:#f1f3f5;font-family:'Noto Sans KR',sans-serif;color:#333;line-height:2;font-size:15px;}
 .bar{background:#fff;border-bottom:1px solid #e5e7eb;padding:14px 20px;font-size:13px;color:#6b7280;text-align:center;}
 .bar b{color:#C21414;}
 .paper{max-width:620px;margin:24px auto 60px;background:#fff;padding:32px 24px 48px;border-radius:10px;box-shadow:0 1px 4px rgba(0,0,0,.06);}
 table{width:100%;}
</style></head><body>
<div class="bar">이 화면은 <b>미리보기</b>입니다 · 네이버 블로그에 붙여넣을 파일은 <b>본문.html</b> 입니다</div>
<div class="paper">
[여기에 본문.html 내용 그대로]
</div></body></html>
```
> 아파트스퀘어 글이면 `.paper` 의 `max-width` 는 그대로 두되 본문 문단이 가운데 정렬입니다.

**③ `정보.md`**
```markdown
| 항목 | 내용 |
|---|---|
| 브랜드 | |
| 글 종류 | 일반 / 뉴스 |
| 여정 단계 | |
| 페르소나 | |
| 핵심 키워드 | |
| 분량 | 0,000자 |
| 검수 | ⬜ 미완료 (`/cm-review` 실행 필요) |
| 발행일 | |
| 발행 URL | |

## 제목 3안
1. 2. 3.

## 메타설명 (80자)

## 해시태그

## 대표 이미지 아이디어 3개

## 사진 자리 목록 (촬영·선택 필요)
- 1) …

## 기준이 없어 제가 정한 것
- …

## [확인 필요] 로 비워둔 곳
- …

## 자동 교정한 표현
| 원래 | 바꾼 것 | 근거 |
```

## 6단계 — 보고 (짧게)

1. 저장 경로
2. 제목 3안
3. **`[확인 필요]` 로 비워둔 곳** ← 사용자가 사실을 채워야 하는 부분
4. **기준이 없어 제가 정한 것**
5. 다음 할 일: `/cm-review 콘텐츠/블로그/폴더명/본문.html`

그리고 **`미리보기.html` 을 사용자에게 파일로 보내서 눈으로 확인**하게 합니다.

원고 전문을 터미널에 다시 쏟아내지 마세요. 파일을 열어보면 됩니다.

## 절대 하지 않는 것

- 확인되지 않은 수치·인증·수상·순위·가격을 지어내는 것
- 사용자를 대신해 블로그에 발행하는 것
- `브랜드기준/` 을 확인 없이 고치는 것 (제안만 하고 반영은 사용자가 결정)
