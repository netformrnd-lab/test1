# 카페 글 작성 (전아모 등 아파트 카페)

> 카페는 블로그가 아닙니다. **광고처럼 보이면 바로 묻힙니다.**
> 커뮤니티 멤버가 현장 이야기를 나누는 느낌이어야 합니다.

## 1단계 — 기준을 읽는다

- `브랜드기준/08-블로그-서식.md` 의 **`4. 전아모 카페 글`** 섹션 ← 문체·구조 원본
- `브랜드기준/01-브랜드-원메시지.md` 의 **아파트스퀘어** 블록 (앱, 역할 경계, 허용 표현)
- `브랜드기준/02-톤앤매너.md` 의 **아파트스퀘어 금지어·자동 교정**
- `브랜드기준/03-페르소나.md` 의 A-1~A-3
- `콘텐츠/카페/` 최근 글 — 같은 얘기 반복 방지

## 2단계 — 유형과 페르소나를 정한다 (최대 3개 질문)

**글 유형 6가지** (`08-블로그-서식.md` 4-2 참고)

| 유형 | 언제 쓰나 |
|---|---|
| 시공 과정 설명 | 공종을 알려주고 싶을 때 |
| 판단 기준 제시 | "뭘 먼저 해야 하나" 고민에 답할 때 |
| 투명성 증명 | 앱·감리보고서를 보여줄 때 |
| 단지 사례 | 실제 사례를 풀 때 |
| 브랜드 소개 | 서비스 구조를 설명할 때 |
| 참여 유도 | 댓글을 받고 싶을 때 (전아모에서 참여율 높음) |

**페르소나**
- `박미정 소장` — 전문용어 OK, 법령·서류 근거 중심
- `김영수 회장` — 숫자 먼저, "감리"로 안심, 전화 전환 목표
- `김선희 부회장` — 일상어, 사례 중심, before/after, 입소문

지정이 없으면 골라 쓰고 **"김선희 부회장 기준으로 잡았습니다"** 라고 알린 뒤 진행합니다.

## 3단계 — 쓴다

### 문체
- 시작: **"안녕하세요. 아파트스퀘어 건축사 조현식입니다."**
- **1인칭 "저는 / 저희는"**
- 전문가지만 가볍고 친근하게. 커뮤니티 멤버처럼
- 현장 이야기를 가볍게 공유하는 느낌
- 이모지 적당히 (남발 ❌)
- 이미지 자리는 `[📷 이미지 자리: 설명]` 텍스트로 표기 (카페는 HTML 안 씁니다)

### 고객 경험으로 보여주기 (정보 나열 ❌)
`02-톤앤매너.md` 4번을 그대로 따릅니다.
"감리보고서를 앱으로 공유합니다" ❌
→ "공사 3일차 아침, 앱에 알림이 왔습니다. '오늘 3동 균열보수 작업 완료, 사진 첨부.'" ✅

### 마무리
> "비슷한 상황이신 분들, 혼자 고민하지 마시고 댓글이나 연락처로 편하게 말씀해 주세요.
> 저희가 함께 방법을 찾아드리겠습니다."

연락처: **1600-6069** (22년차 건축사 상담)

### 🚨 카페에서 특히 조심할 것
- **본문에서 독자를 직접 호칭하지 않습니다** ("관리소장님/동대표님" ❌)
  → "많은 단지들이 / 현장에서 자주 보는 상황은" ✅
- **역할 경계**: 검토·확인·진단·감리까지만. "우리가 골라준다/시공한다" ❌
- **금지**: 보장 / 감독 / 안전 관리 / 열화상 카메라 / 실적 건수 / 부실공사·비리·뒷돈 / 미검증 통계
- **확립된 현재형**: "이제부터/새롭게/최근/도입" ❌ → "아파트스퀘어는 ~합니다" ✅
- 카페 규정상 홍보 글이 제한될 수 있습니다. **정보가 8, 브랜드가 2** 비율을 지킵니다.
