# 고객 여정 맵 설계

**2026년 CRM마케팅팀 1순위 과제입니다.** 팀 3명이 함께 확정하는 문서이고, AI는 초안까지 만듭니다.

## 1단계 — 재료를 모은다

- `브랜드기준/03-페르소나.md` — **여정은 페르소나별로 다릅니다.** 없으면 `/cm-persona` 를 먼저 권합니다.
- `브랜드기준/07-VOC.md` — 각 단계에서 고객이 실제로 한 말
- `브랜드기준/01-브랜드-원메시지.md` — 단계별 메시지의 뿌리
- `브랜드기준/06-키워드맵.md` — 인지·관심·비교 단계의 검색 유입
- `콘텐츠/` 전체 — **이미 있는 콘텐츠를 단계에 매핑**합니다. 이게 핵심입니다.

## 2단계 — 8단계를 채운다

각 단계마다 9칸을 채웁니다.

| 칸 | 무엇을 |
|---|---|
| 고객의 상태 | 이 단계에서 고객이 처한 상황 |
| 고객의 고민 | **VOC 원문 인용.** 없으면 `(추정)` |
| 필요한 정보 | 다음 단계로 가려면 무엇을 알아야 하나 |
| 봐야 할 콘텐츠 | 구체적 콘텐츠 유형과 제목안 |
| 만나는 채널 | 검색 / SNS / 홈페이지 / 이메일 / 오프라인 |
| 전할 메시지 | 원메시지를 이 단계 언어로 |
| 담당 | 검색·오운드 / 소셜·PR / 전환·리텐션 |
| **지금 있는 것** | `콘텐츠/` 에서 실제로 찾은 파일. **없으면 "없음"이라고 정직하게** |
| **비어 있는 것** | 이 단계에 필요한데 없는 것 → **이게 할 일 목록입니다** |

### 단계별로 놓치기 쉬운 것

| 단계 | 자주 비어 있는 것 |
|---|---|
| 인지 | 브랜드를 모르는 사람이 검색할 **문제 중심 키워드** 콘텐츠 |
| 관심 | 우리 얘기만 하고 **고객 상황별 정보**가 없음 |
| **비교** | **비교 기준표.** 여기가 가장 자주 비어 있고 이탈이 큽니다 |
| 문의 | 문의 직전의 불안(영업 전화, 비용)을 없애주는 자료 |
| 계약 | 절차·기간·필요 서류 안내 |
| 이용 | 이용 중 안내 — 거의 항상 비어 있습니다 |
| 재구매 | 재구매 트리거 캠페인 |
| 추천 | 공유하기 쉬운 한 장 요약 |

## 3단계 — 이탈 지점을 짚는다

`지금 있는 것 = 없음` 인 단계가 **이탈 후보**입니다.
데이터가 있으면 근거를 붙이고, 없으면 이렇게 표시합니다.
> 데이터 없음 — 확인하려면 (홈페이지 유입/이탈, 문의 전환율) 이 필요합니다.

**숫자를 지어내지 마세요.** `PENDING` 상태로 두는 게 정확합니다.

## 4단계 — 반영과 다음 액션

1. `브랜드기준/04-고객여정맵.md` 에 반영. 기존 내용 삭제 전 사용자 확인.
2. 맨 아래 `이탈 지점 기록` 표를 채웁니다.
3. **우선순위 3개**를 제안합니다: 비어 있는 칸 중 가장 먼저 만들어야 할 콘텐츠 3개
   → 바로 `/cm-blog`, `/cm-sales` 로 이어질 수 있게 주제·키워드까지 적어줍니다.

## 5단계 — 보고

- 채운 단계 / 비어 있는 단계 개수
- **가장 크게 비어 있는 단계 1개**와 그 이유
- 다음에 만들 콘텐츠 3개 (담당자별로 나눠서)
- 팀 3명이 같이 결정해야 할 쟁점

## 절대 하지 않는 것

- 이탈률·전환율 수치를 지어내는 것
- 있지도 않은 콘텐츠를 "지금 있는 것"에 적는 것 (`콘텐츠/` 를 실제로 확인)
- 사용자 확인 없이 기존 여정 맵을 덮어쓰는 것
