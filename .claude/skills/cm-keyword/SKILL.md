# 키워드 리서치 · 검색 노출 점검

CRM마케팅팀 **검색·오운드 담당자**용입니다. 블로그를 쓰기 **전에** 돌리는 도구입니다.

## 1단계 — 기준을 읽는다

- `브랜드기준/06-키워드맵.md` — 이미 잡아둔 키워드, 안 건드리기로 한 키워드
- `브랜드기준/03-페르소나.md` — **고객이 실제로 검색창에 치는 말**
- `브랜드기준/07-VOC.md` — 고객이 쓴 단어 (= 검색어 후보)
- `브랜드기준/04-고객여정맵.md` — 어느 단계의 키워드를 찾는가
- `콘텐츠/블로그/` — 이미 다룬 키워드 (자기 글끼리 경쟁하면 손해)

## 2단계 — 실제 검색 결과를 확인한다

**웹 검색 도구를 쓸 수 있으면 반드시 실제로 확인합니다.**

- 그 키워드로 지금 상위에 뜨는 글이 무엇인지
- 경쟁사가 이미 먹었는지
- 우리 글이 몇 위인지

**검색량 숫자는 도구 없이 알 수 없습니다.**
"월 3,200회" 같은 수치를 **절대 지어내지 마세요.**
대신 이렇게 씁니다: `검색량 미확인 — 네이버 키워드도구 확인 필요`

## 3단계 — 세 종류로 뽑는다

### ① 핵심 키워드 (3~5개)
브랜드가 반드시 1페이지에 있어야 하는 말. 경쟁이 셉니다. 장기전입니다.

### ② 롱테일 키워드 (10~15개)
3어절 이상, 의도가 뚜렷한 말. **여기부터 먹고 올라갑니다.**
- 지역형: `OO공법 + 지역명`
- 비용형: `OO 시공 비용 얼마`
- 비교형: `OO vs △△ 차이`
- 문제형: `OO 하자 원인`
- 시기형: `2026 OO 기준`

### ③ 질문형 키워드 (5~10개) — AEO / GEO
사람이 문장으로 검색하거나 AI에게 묻는 말.
각 질문에 **40자 이내 직답**을 함께 씁니다. 이게 그대로 블로그 FAQ가 됩니다.

## 4단계 — 우선순위를 매긴다

| 기준 | 배점 |
|---|---|
| 고객 의도가 구매에 가까운가 (비교·문의 단계) | ★★★ |
| 우리가 실제 답을 갖고 있는가 (증거·사례) | ★★★ |
| 경쟁이 약한가 (검색 결과에 전문 콘텐츠가 적은가) | ★★ |
| 원메시지와 연결되는가 | ★★ |
| 이미 우리 글이 있는가 (있으면 새로 쓰지 말고 보강) | ★ |

**결과: "다음에 쓸 글 3개"까지 좁혀서 제안합니다.** 30개 목록만 주면 아무도 안 씁니다.

## 5단계 — 반영과 보고

1. `브랜드기준/06-키워드맵.md` 표에 추가합니다.
2. 포털 순위를 확인했으면 `포털 1페이지 점검 기록` 표에 오늘 날짜로 기록합니다.
3. 보고:
   - **다음에 쓸 글 3개** (키워드 + 제목안 + 여정 단계 + 이유)
   - 확인이 필요한 것 (검색량 등 도구 없이 못 본 것)
   - 바로 이어서: `/cm-blog [키워드]`

## 절대 하지 않는 것

- **검색량·경쟁도 수치를 지어내는 것** (가장 흔한 실수입니다)
- 확인 안 한 순위를 사실처럼 쓰는 것
- `06-키워드맵.md` 의 "안 건드리는 키워드"를 제안하는 것
