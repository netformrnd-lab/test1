# 고객 페르소나 정의서 작성

CRM마케팅팀 **3명이 함께** 확정하는 문서입니다. AI는 초안까지만 만듭니다.

> ⚠️ 페르소나는 인구통계가 아니라 **고객이 실제로 하는 말과 고민**입니다.
> 근거 없이 "30~50대 남성, 안정 추구형" 같은 걸 지어내면 아무도 안 씁니다.

## 1단계 — 근거를 모은다

- `브랜드기준/07-VOC.md` — **가장 중요한 재료**
- `브랜드기준/03-페르소나.md` — 기존 페르소나 (갱신인지 신규인지 판단)
- `브랜드기준/01-브랜드-원메시지.md` — 어느 브랜드의 고객인가
- 사용자가 붙여넣은 인터뷰·문의·후기 원문

**VOC가 비어 있고 사용자가 원문도 안 줬다면**, 지어내지 말고 이렇게 안내합니다.
> 지금은 근거가 없어서 **가설 페르소나**밖에 못 만듭니다.
> 문의 내역이나 상담 기록 10건 정도만 붙여넣어 주시면 실제 근거로 만들 수 있어요.
>
> 그래도 진행하시면, 모든 항목에 `(가설)` 표시를 붙여서 만들어 드립니다.

사용자가 가설로 진행을 원하면 **모든 항목에 `(가설)` 을 표시**하고 만듭니다.

## 2단계 — 원문에서 뽑는다

붙여넣은 원문에서 이것들을 **원문 그대로** 추출합니다.

1. **반복되는 말** — 3번 이상 나온 표현. 그 단어가 콘텐츠 제목이 됩니다.
2. **진짜 고민** — 표면 vs 실제
   - "비싸다" → 진짜: "비교할 기준이 없어서 비싼지 아닌지 모른다"
   - "생각해볼게요" → 진짜: "내부 결재를 받을 근거 자료가 없다"
3. **결정하는 순간** — 무엇을 보고 넘어왔는가
4. **이탈하는 순간** — 무엇을 보고 나갔는가
5. **정보를 찾는 경로** — 어디서 우리를 알게 됐는가

**요약하지 말고 원문을 인용합니다.** 정제하면 고객의 목소리가 사라집니다.

## 3단계 — 정의서를 쓴다

`브랜드기준/03-페르소나.md` 의 형식을 **그대로** 따릅니다.
브랜드당 **2~3명까지만.** 그 이상은 아무도 안 봅니다.

각 항목마다 근거를 표시합니다.
- 근거 있음: 원문 인용 그대로
- 추론: `(추정)`
- 근거 없음: `(가설)`

## 4단계 — 반영한다

1. `브랜드기준/03-페르소나.md` 에 추가하거나 갱신합니다. **기존 내용을 지우기 전에 사용자에게 확인**합니다.
2. 맨 아래 `업데이트 기록` 표에 한 줄 추가합니다 (날짜 / 바뀐 것 / 근거 / 작성자).
3. 페르소나가 바뀌면 영향받는 곳을 알려줍니다:
   > 이 페르소나 변경은 `04-고객여정맵.md` 의 OO 단계와 관련이 있습니다. 같이 보시겠어요?

## 5단계 — 보고

- 만든 페르소나 이름과 한 줄 요약
- **근거가 있는 항목 / (추정) / (가설) 개수**
- 팀 3명이 같이 확정해야 할 쟁점 2~3개
- 더 필요한 근거 (예: "이용·재구매 단계 고객 인터뷰가 없습니다")

## 절대 하지 않는 것

- 근거 없는 인구통계·성격 유형을 사실처럼 쓰는 것
- 고객의 말을 예쁘게 다듬어서 옮기는 것
- 사용자 확인 없이 기존 페르소나를 덮어쓰는 것
