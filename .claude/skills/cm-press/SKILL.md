# 보도자료 작성

CRM마케팅팀 **소셜·PR 담당자**용입니다.

> ⚠️ **보도자료는 마케팅 글이 아닙니다.**
> 형용사를 빼고 **사실만** 씁니다. 기자가 손을 안 대고 쓸 수 있어야 좋은 보도자료입니다.

## 1단계 — 사실부터 확보한다

보도자료는 **사실이 없으면 쓸 수 없습니다.** 아래를 사용자에게 **한 번에 모아서** 묻습니다.
(사용자가 이미 준 것은 빼고 물어봅니다.)

- 무엇이 일어났나 (수상 / 인증 / 협약 / 신제품 / 투자 / 실적 …)
- 정확한 명칭 (상 이름, 인증명, 기관명, 제품명 — **약칭 말고 정식 명칭**)
- 날짜 (발표일 / 시행일)
- 숫자 (금액, 건수, 규모 — 공개 가능한 것만)
- 인용할 사람 (직책 + 이름)
- 배포 희망일
- 담당자 연락처

**모르는 항목은 지어내지 말고 `[확인 필요]` 로 비워둡니다.**

동시에 `브랜드기준/01-브랜드-원메시지.md` 의 **"전사 공통 → 회사 소개 한 문단"** 과
`02-톤앤매너.md` 의 회사명 정식 표기를 읽어옵니다.

## 2단계 — 보도자료 구조

```
[제목]  25자 내외. 사실 그대로. "혁신적인" 같은 형용사 금지.
[부제]  제목이 못 담은 핵심 사실 한 줄. (선택)

[리드문]  첫 문단에서 5W1H를 다 답한다. 3문장 이내.
          "넷폼알앤디(대표 OOO)는 O월 O일 ~했다고 밝혔다."

[본문 1] 사실의 구체적 내용 — 무엇을, 얼마나, 어떻게
[본문 2] 배경·의미 — 왜 이게 중요한가
[본문 3] 인용문 — "OOO 대표는 '~'라고 말했다."
         ※ 인용문에서만 주관적 표현이 허용됩니다.
[본문 4] 향후 계획 (있으면)

[회사 소개]  01-브랜드-원메시지.md 의 표준 문단을 그대로 사용
[담당자]     이름 / 직책 / 전화 / 이메일
```

## 3단계 — 문체 규칙

- 문체는 `~했다` **평서체**. (`02-톤앤매너.md` 보도자료 행 확인)
- 주어는 회사 정식 표기.
- **형용사·부사를 뺍니다.** "크게 성장했다" ❌ → "전년 대비 32% 증가했다" ✅
- 최상급 표현은 **공식 근거가 있을 때만**, 근거를 문장 안에 밝힙니다.
  (예: "OO협회 발표 기준 국내 1위")
- 분량 800자 내외. 길면 기자가 안 읽습니다.

## 4단계 — 저장

`콘텐츠/보도자료/YYYY-MM-DD-주제.md`
맨 위에 배포 정보 표(배포 희망일 / 대상 매체 / 담당자 / 검수 상태),
그 아래 **복사용 전문**, 마지막에 **함께 보낼 자료 목록**(사진, 로고, 참고자료).

## 5단계 — 보고

저장 경로 / 제목 2안 / **`[확인 필요]` 로 비워둔 사실 목록** / 다음 단계 `/cm-review`.

## 절대 하지 않는 것

- 사실을 추측해서 채우는 것 (**보도자료에서는 이게 가장 위험합니다**)
- 근거 없는 최상급·수치 표기
- 대신 매체에 배포하는 것
