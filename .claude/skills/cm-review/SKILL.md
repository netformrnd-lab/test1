# 콘텐츠 검수 (발행 전 게이트)

`브랜드기준/05-콘텐츠-제작기준.md` 의 체크리스트대로 검사합니다.

> ⚠️ **AI는 통과 여부를 판단할 뿐, 발행하지 않습니다.**
> 최종 발행 결정은 반드시 사람이 합니다.

## 1단계 — 대상과 기준을 읽는다

1. 검수할 콘텐츠 (경로를 받았으면 그 파일, 안 받았으면 `콘텐츠/` 에서 가장 최근 파일을 제안)
2. `브랜드기준/05-콘텐츠-제작기준.md` — **체크리스트 원본**
3. `브랜드기준/01~04, 06` — 대조 기준
4. `콘텐츠/` 안 최근 3개월 같은 채널 글 — **중복 검사용**

## 2단계 — 세 등급으로 검사한다

### A. 발행 금지 항목 (하나라도 걸리면 🔴 반려)
A1 사실 오류 · A2 근거 없는 최상급 · A3 미확정 가격 · A4 경쟁사 비방 · A5 고객 동의 · A6 저작권

**A1·A2 검사 방법**: 원고에 나온 모든 수치·인증명·수상·순위를
`01-브랜드-원메시지.md` 의 **실적 표**와 하나씩 대조합니다.
**표에 없으면 🔴 입니다.** "그럴듯하니까 맞겠지"는 통과 사유가 아닙니다.
대형 단지 실명(헬리오시티·잠실 엘스·래미안 등)은 **공개 동의 확인 여부**까지 봅니다(A5).

### B. 브랜드 기준 (걸리면 🟡 수정 후 재검수)

## 3단계 — 결과를 이렇게 낸다

```
## 검수 결과: 🔴 반려 / 🟡 수정 필요 / 🟢 발행 가능

| 등급 | 항목 | 결과 | 문제가 된 문장 | 이렇게 고치세요 |
|---|---|---|---|---|
| A2 | 근거 없는 최상급 | 🔴 | "업계 최고의 시공 품질" | 증거 항목에 근거 없음 → "OO인증을 받은 시공 방식" 으로 |
| B2 | 톤앤매너 | 🟡 | "정말 대박인 결과죠!" | 금지 표현. "예상보다 큰 차이가 나타났습니다" |
| C2 | CTA | 🟠 | 견적 문의 + 카탈로그 다운로드 | CTA 2개 → 여정 단계상 "견적 문의" 하나만 |
```

**규칙**
- **문제가 된 실제 문장을 그대로 인용**합니다. "톤이 안 맞음" 같은 뭉뚱그린 지적 금지.
- **고칠 문장을 함께 제시**합니다. 지적만 하지 않습니다.
- 검사할 기준이 `브랜드기준/` 에 비어 있으면 그 항목은 **⬜ 판단 불가**로 표시하고,
  "이 항목을 검사하려면 `02-톤앤매너.md` 의 금지어를 채워주세요"라고 알립니다.
  **비어 있는 기준으로 임의 판단하지 마세요.**
- 중복 검사는 실제로 최근 파일을 읽고 겹치는 소제목·문단을 지목합니다.

## 4단계 — 마무리

1. 원본 파일 맨 위 표의 `검수` 칸을 결과로 업데이트합니다.
   (`⬜ 미완료` → `🔴 반려 (2026-00-00)` / `🟢 통과 (2026-00-00)`)
2. 사용자가 "고쳐줘"라고 하면 지적한 대로 수정하고 다시 검수합니다.
3. 🟢 통과일 때만 이렇게 안내합니다:
   > 기준상 문제는 없습니다. **A항목(사실·가격·동의)은 사람이 한 번 더 확인하고 발행하세요.**

## 절대 하지 않는 것

- 대신 발행하는 것
- 기준이 비어 있는데 "통과"라고 하는 것
- 근거 없이 🟢 를 주는 것 — 애매하면 🟡 로 두고 이유를 씁니다
