# 세일즈·전환 콘텐츠 문안

CRM마케팅팀 **전환·리텐션 담당자**용입니다.
고객 여정에서 **문의 → 계약 → 이용 → 재구매** 구간을 담당하는 자료를 만듭니다.

## 1단계 — 기준을 읽는다

- `브랜드기준/01-브랜드-원메시지.md` — 특히 **증거 항목**. 세일즈 자료는 근거가 전부입니다.
- `브랜드기준/02-톤앤매너.md` — 해당 채널 행
- `브랜드기준/03-페르소나.md` — 이 자료를 받는 사람의 **결정 순간 / 이탈 순간**
- `브랜드기준/04-고객여정맵.md` — 이 자료가 채우는 단계
- `브랜드기준/07-VOC.md` — **고객이 실제로 묻는 질문.** FAQ와 반박 논리의 재료입니다.

## 2단계 — 유형별로 쓴다

### 랜딩페이지
```
1 헤드라인      고객의 목적을 그대로. 25자 이내. 기능이 아니라 결과를 말한다.
2 서브헤드      한 문장으로 어떻게 되는지
3 문제 제기     페르소나의 진짜 고민 3개 (VOC 원문 활용)
4 해법          우리가 어떻게 푸는가 3단계
5 근거          증거 항목만 사용 — 인증·사례·수치. 없으면 [확인 필요]
6 비교          고객이 저울질하는 기준으로 표 1개
7 FAQ           VOC에서 실제로 나온 질문 5개
8 CTA           딱 하나. 문구는 행동 그대로. ("무료 견적 받기")
```
**CTA는 하나입니다.** 두 개면 아무것도 안 눌립니다.

### 제안서
```
1 표지
2 고객 문제 정의   ← 우리 소개보다 먼저. 고객 말로 시작합니다.
3 제안 요약        한 장으로 결론
4 해법 상세
5 근거·사례
6 진행 절차·일정
7 비용 안내 방식   ← 확정 가격은 [확인 필요]로 두고 사람이 채웁니다
8 회사 소개
9 담당자·다음 단계
```

### 카탈로그 / 리플렛
- 지면 순서 = **고객이 궁금해하는 순서** (07-VOC.md 참고)
- 한 면에 메시지 하나
- 사양·수치는 원문 확인된 것만

### 이메일 / 문자
| 항목 | 규칙 |
|---|---|
| 제목·첫 줄 | 열리는지가 여기서 갈립니다. 25자 이내 |
| 본문 | 이메일 300자 / 문자 90자 이내 |
| CTA | 하나 |
| 필수 | 발신자 명시, **수신 거부 안내** (문자는 법적 필수), 광고 표기 |
| 재구매 캠페인 | 이전 이용 내역을 근거로 말합니다. 근거 없으면 보내지 않습니다 |

## 3단계 — 세일즈 자료의 안전 규칙

- **가격·할인율·납기·보증 기간은 절대 추측하지 않습니다.** `[확인 필요: 항목명]` 으로 비웁니다.
- 성능·효과 주장은 `01-브랜드-원메시지.md` 증거 항목에 있는 것만.
- 경쟁사 비교는 **공개된 사실 기준으로만**. 경쟁사명을 직접 쓸 때는 팀장 확인 필요라고 표시합니다.
- 고객 사례는 **동의받은 것만**. 확인 안 됐으면 `[동의 확인 필요]`.

## 4단계 — 저장

`콘텐츠/세일즈자료/YYYY-MM-DD-브랜드-유형.md`
맨 위 정보 표(브랜드 / 유형 / 여정 단계 / 페르소나 / 검수 상태),
그 아래 **복사용 전문**, 마지막에 **디자인 전달 메모**(분량, 이미지 자리, 강조할 문장).

## 5단계 — 보고

저장 경로 / 헤드라인 3안 / `[확인 필요]` 목록 / 다음 단계 `/cm-review`.

## 절대 하지 않는 것

- 가격·납기·보증 등 **약속에 해당하는 내용을 지어내는 것**
- 동의 확인 안 된 고객 사례·후기 사용
- 대신 발송·게시하는 것
