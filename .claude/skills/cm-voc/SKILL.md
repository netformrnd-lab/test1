# VOC 정리 · 축적

**2026년 CRM마케팅팀 과제 "고객 데이터를 축적한다"** 가 실행되는 도구입니다.
하루 1건이라도 쌓는 게 중요합니다.

## 1단계 — 원문을 받는다

사용자가 붙여넣은 덩어리(문의 내역, 통화 메모, 리뷰, DM, 카페 글, 영업팀 전달 내용)를 받습니다.
형식이 엉망이어도 괜찮습니다. **정리는 이 도구가 합니다.**

원문이 없으면 어디서 가져오면 되는지 알려줍니다.
> 홈페이지 문의 게시판 / 카카오 상담 / 인스타 DM / 네이버 리뷰 / 영업팀 상담 메모
> — 아무거나 복사해서 그냥 붙여넣어 주세요. 형식 안 맞아도 됩니다.

기존 `브랜드기준/07-VOC.md` 와 `03-페르소나.md` 를 읽어 중복과 맥락을 파악합니다.

## 2단계 — 한 건씩 분류한다

각 건마다:

| 항목 | 규칙 |
|---|---|
| 날짜 | 원문에 있으면 그대로, 없으면 `미상` |
| 브랜드 | 판단 가능하면 적고, 아니면 `미상` |
| 출처 | 전화 / 문의폼 / 카페 / DM / 리뷰 / 인터뷰 / 영업팀 |
| 여정 단계 | 인지·관심·비교·문의·계약·이용·재구매·추천 |
| **원문** | **고객이 쓴 말 그대로.** 오타·비문도 그대로 둡니다 |
| 해석 | 진짜 고민. 추측이면 `(추정)` |
| 유형 | 불만 / 질문 / 칭찬 / 요청 / 오해 |
| 조치 | 어떤 콘텐츠로 답할 것인가 |

### 개인정보는 지웁니다
이름·전화번호·주소·계좌·이메일은 **저장 전에 마스킹**합니다.
(`김OO`, `010-****-1234`, `서울 강남구`)
**원문 보존보다 개인정보 보호가 먼저입니다.**

### 표면 vs 진짜 고민
| 고객이 한 말 | 진짜 고민 |
|---|---|
| "좀 비싸네요" | 비교할 기준이 없어서 비싼지 판단이 안 됨 |
| "생각해볼게요" | 내부 결재용 근거 자료가 없음 |
| "연락 주세요" 후 잠수 | 영업 전화가 부담됨 |
| "다른 데도 알아보는 중" | 비교 기준표가 없음 |

## 3단계 — 패턴을 뽑는다

1. **반복되는 말 TOP 3** — 몇 번 나왔는지 세고, 그 단어를 원문 그대로 씁니다.
   반복되는 말은 **곧 블로그 제목**입니다.
2. **우리가 아직 답 못 한 것** — 콘텐츠로 답이 없는 질문
3. **오해 목록** — 고객이 잘못 알고 있는 것 + 어디서 생긴 오해인지
4. **여정 단계별 분포** — 어느 단계 VOC가 몰려 있는가 (= 그 단계에 문제가 있다는 신호)

## 4단계 — 반영

1. `브랜드기준/07-VOC.md` 의 `기록` 표에 **한 건씩 행 추가** (기존 행은 지우지 않습니다)
2. `반복되는 말 TOP` 갱신
3. `오해 목록` 갱신
4. 페르소나에 영향이 크면 알립니다:
   > 이 VOC 12건은 `03-페르소나.md` 의 "진짜 고민"과 다릅니다. `/cm-persona` 로 갱신하시겠어요?

## 5단계 — 보고

- 정리한 건수 / 유형별 개수 / 여정 단계별 분포
- **반복되는 말 TOP 3**
- **바로 만들 수 있는 콘텐츠 3개** (VOC 근거 + 제목안)
- 마스킹한 개인정보 건수

## 절대 하지 않는 것

- 고객의 말을 예쁘게 다듬는 것 (**원문 그대로가 자산입니다**)
- 없는 VOC를 만들어내는 것
- 개인정보를 그대로 저장하는 것
- 기존 기록을 덮어쓰는 것 (VOC는 계속 쌓기만 합니다)
