## 방법 A — 저(Claude)에게 맡기기 ※ 추천

터미널을 안 쓰셔도 됩니다. **딱 3단계**입니다.

### 1) Cloudflare 계정 만들기 (2분, 무료)

https://dash.cloudflare.com/sign-up
이메일과 비밀번호만 있으면 됩니다. **카드 등록 안 합니다.**

가입 후 왼쪽 메뉴에서 **Compute (Workers)** 를 한 번 눌러주세요.
`○○○.workers.dev` 주소를 정하라고 나오면 원하는 이름을 넣습니다.
(예: `netform` → 최종 주소가 `crm-ai-office.netform.workers.dev` 가 됩니다)

### 2) API 토큰 만들기 (2분)

1. 오른쪽 위 프로필 아이콘 → **My Profile**
2. 왼쪽 탭에서 **API Tokens**
3. **Create Token** 버튼
4. 목록에서 **Edit Cloudflare Workers** 옆의 **Use template** 클릭
5. 아래로 내려서 **Continue to summary** → **Create Token**
6. 화면에 뜨는 긴 문자열을 복사 (이 화면을 벗어나면 다시 못 봅니다)

### 3) 토큰을 환경변수로 넣기

🔒 **토큰을 채팅창에 붙여넣지 마세요.** 비밀번호와 같습니다.

Claude Code 웹 화면의 **환경(Environment) 설정 → 환경변수** 에 넣어주세요.

| 이름 | 값 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 방금 복사한 문자열 |

다 하시고 저에게 **"토큰 넣었어"** 라고만 말씀해 주시면 제가 올리고 주소를 드립니다.

> 나중에 언제든 같은 화면에서 토큰을 **Delete** 하면 접근이 끊깁니다.
> 이 토큰은 Workers 배포 권한만 있고, 다른 건 못 합니다.

## 방법 B — 직접 하기

본인 컴퓨터에 **Node.js 22 이상**이 설치돼 있어야 합니다. ([nodejs.org](https://nodejs.org) LTS)

```bash
cd ai-office
npm install
npx wrangler login
npm run build
npx wrangler deploy
```

`npx wrangler login` 을 치면 브라우저가 열리고 Cloudflare 로그인 화면이 나옵니다.
허용하면 됩니다. 마지막 줄에 주소가 출력됩니다.

## 올린 뒤

### 내용을 바꾸면?

`ai-office/company.config.ts` 를 고친 다음 다시 올려야 화면에 반영됩니다.
저에게 **"사무실 다시 올려줘"** 라고 하시면 됩니다.
(자동으로 갱신되지 않습니다. 올린 시점의 상태가 그대로 유지됩니다)

### ⚠️ 주소를 아는 사람은 누구나 볼 수 있습니다

기본값은 **전체 공개**입니다. 검색에 잘 걸리지는 않지만, 주소가 유출되면 열립니다.

**보이는 것**: 회사·팀 이름, 12개 팀 구성, AI 직원 이름
**안 보이는 것**: 브랜드기준 파일, 콘텐츠 원고, VOC, 고객 정보 (전부 저장소에만 있고 앱에 없습니다)

회사 이메일로만 열리게 잠그고 싶으시면 **Cloudflare Zero Trust Access** 로 막을 수 있습니다.
50명까지 무료입니다. 필요하시면 말씀해 주세요.

### 🔒 절대 올리면 안 되는 것

`.dev.vars` 파일 (Notion·Discord 연동 키). 지금은 없고, 만들더라도 저장소에 안 올라가게 돼 있습니다.
