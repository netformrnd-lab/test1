=====================================================
 CRM마케팅팀 AI 오피스 — 인터넷에 올리는 방법
=====================================================

이 폴더는 "빌드까지 끝난 상태"입니다.
설치나 빌드를 다시 할 필요가 없습니다.

-----------------------------------------------------
 준비물
-----------------------------------------------------
Node.js 22 이상 하나만 필요합니다.
없으면 https://nodejs.org 에서 LTS 버튼을 눌러 설치하세요.

설치 확인 방법:
  터미널(맥) 또는 명령 프롬프트(윈도우)를 열고
  node -v
  라고 치면 v22.x.x 같은 게 나와야 합니다.

-----------------------------------------------------
 올리는 방법 — 명령어 3줄
-----------------------------------------------------
터미널에서 이 폴더로 이동한 뒤 순서대로 칩니다.

  1) 이 폴더로 이동
     cd (이 폴더를 터미널 창에 드래그하면 경로가 자동으로 들어갑니다)

  2) 크라우드플레어 로그인  ← 브라우저가 열립니다. Allow 누르세요
     npx wrangler login

  3) 올리기
     npx wrangler deploy

3번이 끝나면 마지막 줄에 주소가 나옵니다.
  https://crm-ai-office.○○○.workers.dev
이 주소를 팀에 공유하시면 됩니다.

-----------------------------------------------------
 ⚠️ 크라우드플레어 화면에서 "파일 업로드"는 쓰지 마세요
-----------------------------------------------------
Cloudflare 대시보드에 폴더를 끌어다 놓는 메뉴가 있는데,
그건 "그림·글자만 있는 홈페이지"용입니다.

이 사무실은 캐릭터가 움직이는 프로그램이라
끌어다 놓기로 올리면 빈 화면만 나옵니다.
반드시 위의 명령어 3줄로 올려야 합니다.

-----------------------------------------------------
 화면 내용을 바꾸고 싶으면
-----------------------------------------------------
company.config.ts 파일 하나만 고칩니다. (회사명, 팀 이름, 직원 이름)
고친 뒤에는
  npm install
  npm run build
  npx wrangler deploy
순서로 다시 올려야 반영됩니다.

혼자 하기 번거로우면 Claude에게 "사무실 다시 올려줘" 라고 하세요.

-----------------------------------------------------
 주의
-----------------------------------------------------
· 올린 주소는 링크를 아는 사람이면 누구나 볼 수 있습니다.
  (보이는 것: 팀 이름, 12개 팀 구성, AI 직원 이름
   안 보이는 것: 브랜드기준, 원고, VOC, 고객 정보 — 앱에 안 들어갑니다)
· 무료 요금제로 충분합니다. 카드 등록 안 합니다.
