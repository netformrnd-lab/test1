# 아파트스퀘어 앱 (웹 버전)

아파트 외벽 재도장·방수·하자진단 **감리 보고서 서비스** 앱입니다.
기존 디자인 시안(HTML)을 재활용해 만든 **실행 가능한 웹앱**이며,
나중에 Capacitor로 감싸서 기존 앱스토어·플레이스토어 앱을 업데이트할 예정입니다.

## 폴더 구조

```
app/
├─ index.html      # 앱 본체 (화면 22개가 들어있음)
├─ css/app.css     # 스타일 + Pretendard 폰트
├─ js/app.js       # 화면 전환 로직
└─ assets/         # 이미지·폰트
```

## 실행 방법 (로컬)

```bash
cd app
python3 -m http.server 8099
# 브라우저에서 http://localhost:8099 열기
```

## 사용법

- 오른쪽 아래 **☰ 버튼** → 화면 22개 목록에서 아무 화면이나 눌러 이동 (개발용, 완성 후 제거)
- 주소 뒤에 `#s07` 처럼 붙이면 특정 화면 바로 열기 (딥링크)

## 화면 목록

| 그룹 | 화면 |
|---|---|
| 로그인·승인 | 로그인/회원가입, 승인 대기 |
| 로그인 전(누구나) | 홈, 30초 자가진단, 1:1 문의 |
| 감리사 | 담당 단지 대시보드, 보고서 목록/작성/상세 |
| 입주민·관리소장 | 홈, 보고서 목록, 요약 리포트, 공사 일정, 정보, 문의 |
| 상세 화면 | 무료 진단, 공지사항, 감리 안내(3), 회사 소개, 우수 사례 |
