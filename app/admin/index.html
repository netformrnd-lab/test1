단지별 현장 사진·글을 올리세요. 입주민·감리사 앱의 ‘현장 현황’에 바로 보입니다

📥 아임웹 게시판 엑셀 가져오기

아임웹에서 내보낸 게시판 엑셀(.xlsx)을 선택하면 카테고리(단지)별로 현장 현황에 자동 등록돼요. 여러 파일을 한 번에 선택해도 됩니다. 사진은 아임웹 링크를 그대로 쓰고, 이미 등록된 글은 자동으로 건너뜁니다.
※ 단지명이 자동으로 안 잡히면, 위에서 넣을 단지를 직접 선택하세요. 그러면 올린 파일의 모든 글이 그 단지로 들어가요. (한 파일 = 한 단지일 때 추천)

➕ 현장 기록 추가
