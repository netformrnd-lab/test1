📢 공지사항

➕ 공지 등록

📄 감리일지

감리사가 올린 보고서를 다듬어 입주민에게 공개하세요. ‘입주민 공개’를 켜야 입주민 앱에 보여요

📁 감리일지 PDF 여러 개 올리기

단지를 고르고 감리일지 PDF들(폴더 안 파일 전체 선택)을 올리면, 파일 하나가 감리일지 하나로 등록돼요. 파일명이 제목이 되고, 파일명에 날짜(20260401)·동(927동)이 있으면 자동으로 잡아요.

📷 현장 현황

단지별 현장 사진·글을 올리세요. 입주민·감리사 앱의 ‘현장 현황’에 바로 보입니다

📥 아임웹 게시판 엑셀 가져오기

아임웹에서 내보낸 게시판 엑셀(.xlsx)을 선택하면 카테고리(단지)별로 현장 현황에 자동 등록돼요. 여러 파일을 한 번에 선택해도 됩니다. 사진은 아임웹 링크를 그대로 쓰고, 이미 등록된 글은 자동으로 건너뜁니다.
※ 단지명이 자동으로 안 잡히면, 위에서 넣을 단지를 직접 선택하세요. 그러면 올린 파일의 모든 글이 그 단지로 들어가요. (한 파일 = 한 단지일 때 추천)

➕ 현장 기록 추가

🗑 단지 통째로 삭제

단지를 하나 골라 삭제하면 그 단지의 현장기록·감리일지·일정·계약서·만족도·소장 작성지까지 모두 함께 삭제돼요. 되돌릴 수 없어요.
(회원이 배정된 단지는 먼저 회원을 다른 단지로 옮겨야 삭제돼요)

🗓️ 공사 일정

단지별 방문·점검·공사 일정을 등록하세요 (입주민·감리사 앱 ‘공사 일정’에 바로 보입니다)

➕ 일정 추가

날짜·단지·일정 내용을 입력하면 해당 단지 입주민·감리사에게 바로 보여요

📑 계약서

단지별 계약서(PDF·사진)를 등록·보관하세요. 감리사 앱에서도 열람됩니다 (입주민 열람 불가)

➕ 계약서 등록

단지를 먼저 고르고 파일을 선택하세요

💬 채팅

손님(비로그인) 상담과 입주민·감리사 대화에 답하세요. 손님 문의는 여기서 관리합니다
왼쪽에서 대화를 선택하세요

⭐ NPS

입주민·관리소장 만족도 기반 추천지수(NPS)를 단지별로 확인하세요

🔔 소장님 작성지

관리소장님이 작성 폼(/form/)에서 제출한 내용이 단지별로 모입니다

🏅 감리 우수 사례

전·후 사진과 함께 우수 사례를 등록하세요 (입주민 앱 ‘감리 우수 사례’에 노출됩니다)

➕ 사례 등록

📜 인증·이력 (공신력)

인증서·위촉장 이미지를 올리면 앱 ‘이야기 › 철학’ 탭 아래 인증 섹션에 표시됩니다
⚠️ 개인정보 주의 — 위촉장·자격증에는 대표님의 생년월일·자격번호·주소·관인(도장) 이 담겨 있어요. 공개 앱에 그대로 올리면 노출·도용 위험이 있으니, 개인정보 부분은 가리고(모자이크) 올리시길 권장합니다.

➕ 인증서 추가

여러 장을 한 번에 선택하면 한꺼번에 올라가요. 설명은 비워둬도 되고, 적으면 선택한 모든 장에 같이 붙어요.

📁 리플렛

리플렛 이미지를 올리면 감리사 앱 하단 ‘리플렛’ 탭에 표시됩니다. 감리사가 태블릿에서 확대해 보여주거나, 다운받아 공유할 수 있어요

➕ 리플렛 추가

여러 장을 한 번에 선택하면 순서대로 올라가요. (리플렛이 여러 페이지면 페이지 순서대로 선택하세요.) 설명은 비워둬도 돼요.
