데이터 도구

📥 아임웹 게시판 엑셀 가져오기

아임웹에서 내보낸 게시판 엑셀(.xlsx)을 고르면 카테고리(단지)별로 현장기록에 자동 등록돼요. 여러 파일 한 번에 가능 · 이미 등록된 글은 자동으로 건너뜁니다.

📥 아임웹/홈페이지 문의 엑셀 → 영업 등록

아임웹 관리자에서 문의/상담 신청 내역을 엑셀(.xlsx)로 내려받아 올리면, 영업 파이프라인 ‘문의’ 단계에 자동으로 카드가 만들어져요. 이미 등록된 문의는 자동으로 건너뜁니다.

🔗 구글시트 → 영업 문의 자동 연동

구글시트에서 파일 → 공유 → 웹에 게시 → (해당 시트) CSV 로 만든 주소를 넣으면, 시트에 새 행이 기록될 때마다 영업 ‘문의’ 단계에 자동 등록돼요. (구글이 몇 분 간격으로 갱신) 컬럼은 자동 인식(이름·연락처·단지·공사종류·지역·내용·날짜).

🖼️ 아임웹 사진 → 우리 저장소로 이전

출시 전 1회. 현장기록의 아임웹 링크 사진을 우리 저장소(Supabase)로 옮겨요. 옮기면 아임웹을 닫아도 사진이 사라지지 않아요.

🔒 계약서 비공개 전환

과거 공개 버킷에 올라간 계약서를 비공개(contracts) 버킷으로 옮겨요. 출시 전 1회.
