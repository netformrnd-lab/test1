# 아파트스퀘어 영상 제작실 — PC 설치 안내

이 폴더를 회사 PC에 두고 파일 하나만 더블클릭하면 됩니다.
API 키는 이 PC 안에만 있고 화면에는 나오지 않습니다.

---

## 처음 한 번만 하는 일

### 1. Node.js 설치

https://nodejs.org 에 들어가서 **LTS** 라고 적힌 큰 버튼을 누릅니다.
받아진 파일을 실행하고 계속 "다음"을 누르면 끝입니다. PC를 한 번 껐다 켭니다.

### 2. 설정 파일 만들기

이 폴더의 `설정-예시.txt` 를 복사해서 이름을 **`설정.txt`** 로 바꿉니다.
메모장으로 열어 키를 채웁니다. `=` 뒤에 바로 붙여넣고 따옴표는 쓰지 않습니다.

| 줄 | 무엇 | 어디서 받나 | 없으면 |
|---|---|---|---|
| `HEYGEN_API_KEY` | 영상 제작 | 헤이젠 → Settings → API | 자동 제작이 안 됩니다 |
| `ANTHROPIC_API_KEY` | 1차 검수 | console.anthropic.com → API Keys | 1차 검수를 ChatGPT가 대신합니다 |
| `OPENAI_API_KEY` | 2차 검수 | platform.openai.com → API keys | 2차 검수도 클로드가 봅니다 |

헤이젠 키만 있어도 영상 제작은 됩니다. 검수 키는 나중에 추가해도 됩니다.

### 3. 실행

- **윈도우**: `시작-윈도우.bat` 더블클릭
- **맥**: `시작-맥.command` 더블클릭
  (맥에서 "확인되지 않은 개발자" 경고가 뜨면, 파일을 우클릭 → 열기 → 열기)

처음 한 번은 준비하느라 1~2분 걸립니다. 끝나면 브라우저가 저절로 열립니다.
검은 창은 **닫지 마세요**. 그 창이 제작실입니다. 다 쓰면 닫으면 됩니다.

---

## 쓰는 법

| 탭 | 하는 일 |
|---|---|
| **홈** | 영상 목록, 크레딧, AI가 아는 내용 |
| **기획** | 키워드 넣기 → 현황판에 등록 → 검수 2번 |
| **제작** | 「헤이젠에서 바로 만들기」 — 진짜로 영상이 만들어집니다 |
| **완료** | 발행한 영상과 쓴 크레딧 |

제작 버튼을 누르면 헤이젠이 만들기 시작하고, 보통 3~10분 뒤에
목록에 영상 링크가 저절로 들어옵니다. 그동안 브라우저 창은 열어 두세요.

저장은 이 폴더의 `data` 안에 들어갑니다. 폴더째 복사하면 그대로 옮겨집니다.

## 헤이젠 주소가 안 맞을 때

헤이젠은 계정 종류에 따라 API 주소가 다릅니다. 제작 버튼을 눌렀는데
`HTTP 404` 나 `HTTP 400` 이 뜨면 아래를 한 번 확인하세요.

1. 브라우저 주소창에 `http://localhost:8765/api/heygen/discover` 를 칩니다.
2. 목록이 나옵니다. 읽는 법:
   - **200** → 이 주소는 열려 있습니다
   - **400 / 422** → 주소는 맞는데 보내는 내용이 다릅니다
   - **404** → 없는 주소입니다
   - **401** → 키가 틀렸습니다
3. `200` 또는 `400` 이 뜬 주소를 `설정.txt` 의 `HEYGEN_CREATE_PATH` 에 적고
   제작실을 껐다 켭니다.
4. 그래도 안 되면 `HEYGEN_BODY=agent` 를 `HEYGEN_BODY=avatar` 로 바꿔 보세요.

화면에 뜬 빨간 글씨를 그대로 알려 주시면 맞춰 드리겠습니다.

## 자주 나오는 문제

**"Node.js 가 설치되어 있지 않습니다"**
1번을 안 했거나, 설치 후 PC를 안 껐다 켠 경우입니다.

**"설정.txt 가 없습니다"**
`설정-예시.txt` 를 복사해 이름을 바꾸세요. 윈도우에서 확장자가 안 보이면
`설정.txt.txt` 가 되기 쉬우니, 보기 → 파일 확장명 을 켜고 확인하세요.

**브라우저가 안 열림**
검은 창에 적힌 주소(`http://localhost:8765`)를 직접 입력하세요.

**검수 버튼을 눌렀는데 오류**
화면에 나온 문장이 그대로 원인입니다. 잔액 부족이나 키 오타가 대부분입니다.
