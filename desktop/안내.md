# 아파트스퀘어 영상 제작실 — PC 설치 안내

이 폴더를 회사 PC에 두고 파일 하나를 더블클릭하면 됩니다.
**API 키는 화면에서 넣습니다.** 메모장으로 파일을 고칠 필요 없습니다.

---

## 처음 한 번만

### 1. Node.js 설치

https://nodejs.org 에서 **LTS** 라고 적힌 큰 버튼을 누릅니다.
받아진 파일을 실행하고 계속 "다음"을 누르면 끝입니다. PC를 한 번 껐다 켭니다.

### 2. 실행

- **윈도우**: `시작-윈도우.bat` 더블클릭
- **맥**: `시작-맥.command` 더블클릭
  (맥에서 "확인되지 않은 개발자" 경고가 뜨면 파일을 우클릭 → 열기 → 열기)

처음 한 번은 준비하느라 1~2분 걸립니다. 끝나면 브라우저가 저절로 열립니다.
**검은 창은 닫지 마세요.** 그 창이 제작실입니다.

### 3. 키 넣기

브라우저 화면에서 **[자료] 탭 → 맨 위 「API 키」**.
세 칸에 붙여넣고 **키 저장**을 누르면 화면이 저절로 다시 열립니다.

| 칸 | 무엇에 쓰나 | 어디서 받나 | 없으면 |
|---|---|---|---|
| 헤이젠 | 영상 제작 | 헤이젠 → Settings → API | 「영상 만들기」 버튼이 안 나옵니다 |
| 클로드 | 대본 작성 · 1차 검수 | console.anthropic.com → API Keys | ChatGPT가 대신합니다 |
| ChatGPT | 2차 검수 | platform.openai.com → API keys | 클로드가 2차도 봅니다 |

키는 이 폴더의 `keys.json` 에만 저장됩니다.
화면에는 끝 네 자리만 보입니다(`••••••••1234`).

## 쓰는 법

| 탭 | 하는 일 |
|---|---|
| **홈** | 영상 목록, 크레딧 |
| **기획** | 키워드·대상·공사·하자·길이 → **「프롬프트 생성하기」** 한 번 |
| **제작** | **「영상 만들기」** — 진짜로 헤이젠이 만듭니다 |
| **완료** | 발행한 영상과 쓴 크레딧 |
| **자료** | API 키, 등급표, 검증 수치, 하자 사전 53건 |

「프롬프트 생성하기」를 누르면 네 단계가 자동으로 돕니다.

```
① 클로드가 대본을 씁니다
② 1차 검수 — 클로드 (사실과 규정)
③ 2차 검수 — ChatGPT (연출과 리듬)
④ 지적을 반영해 다시 씁니다
```

그다음 제작 탭에서 「영상 만들기」를 누르면 헤이젠이 만들기 시작하고,
보통 3~10분 뒤에 영상 링크가 목록에 저절로 들어옵니다.
그동안 브라우저 창은 열어 두세요.

영상 목록은 이 폴더의 `data` 안에 저장됩니다. 폴더째 복사하면 그대로 옮겨집니다.

## 헤이젠 주소가 안 맞을 때

헤이젠은 계정 종류에 따라 API 주소가 다릅니다.
「영상 만들기」에서 **HTTP 404** 나 **400** 이 뜨면:

1. [자료] 탭 → API 키 아래 **「헤이젠 주소가 안 맞을 때」** 를 펼칩니다.
2. **주소 확인** 링크를 누르면 목록이 뜹니다. 읽는 법:
   - **200** → 열려 있는 주소
   - **400 / 422** → 주소는 맞고 보내는 내용이 다름
   - **404** → 없는 주소
   - **401** → 키가 틀림
3. `200` 또는 `400` 이 뜬 주소를 **영상 만들기 주소** 칸에 넣고 저장합니다.
4. 그래도 안 되면 **보내는 형식**을 `avatar` 로 바꿔 보세요.

화면에 뜬 빨간 글씨를 그대로 알려 주시면 맞춰 드리겠습니다.

## 자주 나오는 문제

**"Node.js 가 설치되어 있지 않습니다"**
1번을 안 했거나, 설치 후 PC를 안 껐다 켠 경우입니다.

**브라우저가 안 열림**
검은 창에 적힌 주소(`http://localhost:8765`)를 직접 입력하세요.

**「영상 만들기」 버튼이 안 보임**
헤이젠 키가 아직 없습니다. [자료] 탭에서 넣고 저장하세요.

**「프롬프트 생성하기」를 눌렀는데 오류**
화면에 나온 문장이 그대로 원인입니다. 잔액 부족이나 키 오타가 대부분입니다.

**클로드 페이지와 목록이 다릅니다**
맞습니다. PC 제작실은 이 폴더에, 클로드 페이지는 계정에 따로 저장됩니다.
같은 화면이지만 목록은 각각입니다.
