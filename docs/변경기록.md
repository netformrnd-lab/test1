## 2026-10-13 · 입주민 앱 문구 개편

**입주민 버전 문구를 '비상주 감리' 기준에 맞게 정리**
- 소개·서비스·회사소개·우수사례·만족도 등 **입주민에게 보이는 문구**에서
  과장 표현을 실제 역할에 맞게 교체
  - '자재·공정·품질을 **직접 검측 / 단계마다 확인**'(상주 뉘앙스) → 시공자 자료 확인 + **완료 부위 적합 여부 판정**
  - '**하자**를 잡아낸다 / **재시공 필요**' 단정 → **적합 / 부적합 / 판정 보류**
  - '끝까지 **안심**·완벽' → **사진·기록**으로 투명하게
- 회사소개 카드 제목 '끝까지 안심돼요' → **'끝까지 기록해요'**
- '하자 유형별 대처법'(정보성 콘텐츠)은 기존 표현 유지
- 파일: `app/index.html`, `app/js/supabase-app.js`, `app/js/stages.js`
- (574b703, 4a4e004)
