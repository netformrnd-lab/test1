## 2026-10-14 · 감리일지 회차 자동화 (단지+공종 기준)

**감리보고서 회차가 늘 ‘제1차’로만 뜨던 문제 → 1·2·3회차 자동 증가** (황상무님 요청)
- 원인: 회차를 **점검앱의 그 폰(로컬 저장)** 기준으로 세서, 기기가 바뀌거나 데이터가 없으면 계속 제1차
- 해결: **서버(실제 감리일지 기록) 기준**으로 계산 → 기기와 무관하게 자동 1→2→3, **기존 보고서도 자동으로 번호 매겨짐**
- 기준: **같은 단지 + 공종**(예: ○○아파트 옥상방수 1·2·3차)
- 점검앱: 저장할 때 **공종 기록 + 서버 기준 회차**를 제목·내용에 반영
- 대시보드: 감리일지 목록·보기·새 알림에 **‘N회차’ 배지**(소급 적용)
- 콘솔 ‘감리일지 추가’ 폼: **공종 입력**(단지 공종 기본값) + 제목에 ‘제N차’ 자동
- 파일: `app/inspect/index.html`, `app/console/index.html`, `backend/migration-report-worktype.sql`
- ⚙️ 공종별로 정확히 나뉘려면 **`migration-report-worktype.sql` 1회 실행** 필요 (안 해도 단지별 번호는 바로 됨)
- (8b94261)

## 2026-10-14 · 담당 배정 요청 (팀장 → 감리원 수락)

**배정 안 된 현장을 감리원에게 '배정 요청'으로 보내고, 감리원이 앱에서 수락하면 자동 배정** (캘린더 요청 2번)
- 대시보드 **'담당 배정 안 된 현장'** 목록의 각 현장에 **‘📩 배정 요청’ 버튼** → 맡길 감리원을 골라 요청 전송 (요청 후엔 ‘○○님께 요청됨’ 표시 + 취소 가능)
- 지정한 **감리원 앱(홈 상단)에 ‘배정 요청’ 배너** → **수락**하면 그 현장 담당으로 자동 등록(대표 감리원 비어 있으면 함께 채움), **거절**도 가능
- **푸시 알림** — 요청을 보내면 해당 감리원 폰으로 ‘🙋 담당 배정 요청’ 푸시 (기존 FCM 푸시 체계 재사용)
- **푸시 알림 연결 완료** — 기존 운영 푸시 엔진(공용 `notify_push()` 트리거 → Cloudflare 푸시 워커 → FCM)을 그대로 재사용. `assign_requests` INSERT 시 지정 감리원 폰에 **🙋 담당 배정 요청** 푸시 발송
- 웹훅 미설정 상태여도 **감리원이 앱을 열면 요청 배너는 보이게** 처리(안전장치)
- 파일: `app/console/index.html`, `app/index.html`, `app/js/supabase-app.js`, `cloudflare-push-worker/worker.js`, `backend/migration-assign-requests.sql`, `backend/migration-assign-requests-push.sql`

## 2026-10-14 · 캘린더 주간 보기 · 사진 저장

**대시보드 캘린더 — 주간 보기 탭 + 사진 내보내기** (캘린더 요청 1번)
- **월간/주간 토글** 추가 — 주간 보기는 요일별 리스트형으로 한눈에 읽기 쉽게
- **아스퀘(파란) 일정이 파란 도배로 보기 힘들던 문제** 해결 → 또렷한 라벨 + 연한 배경으로
- **달력 가로 잘림 해결** — 긴 단지명이 줄바꿈 안 돼 달력이 오른쪽으로 잘리던 문제 → 긴 이름은 '…'로 줄여 항상 7열이 화면에 맞게
- **가독성(시각 강조)** — **아스퀘(파랑)·정기 방문(초록)**은 또렷하게, 나머지(PT·영업·현설·개인·회의 등)만 회색 + 흐리게로 가라앉혀 한눈에 (월간·주간·날짜별 목록 전체)
- **‘📷 주간 사진 저장’ 버튼** — 이번 주 일정을 PNG 이미지로 내보내기 (담당·분류 필터 반영)
- **담당자 자동 인식** — 담당이 제목에 '이름_'으로 섞여 들어온 아스퀘 일정(예: '김성민_장미마을…')도 담당(👤)으로 표시 (주간·날짜별 목록)

**정기 방문 수정 — 초록 유지 + 옮긴 날짜 고정**
- 정기 방문을 수정하면 **파랑(아스퀘)으로 바뀌던 문제** → **초록(정기 방문)으로 유지** (분류 고정 + 표시 우선순위)
- 그날 못 가서 **다른 날로 옮기거나 삭제하면**, 원래 날짜는 **자동 재생성에서 제외**(건너뛸 날짜로 기억) → 옮긴 게 그대로 유지

**방문 배치표 — 상시 자동 적용** (캘린더 요청 3번)
- **요일·담당만 정해두면** ‘이 달 생성’ 버튼 없이도 **앞으로 6주치 방문이 캘린더·감리원·입주민 앱에 자동으로** 뜸 (로딩 시 누락분 자동 추가)
- **배치를 바꾸면 그 현장만 자동 재동기화** (계획에 없는 미래 방문 삭제 + 새 계획 추가, 과거·‘다녀옴’ 기록은 보존)
- **변동 있을 때만** 그 날짜 일정을 고치면 되는 구조 · 파일: `app/console/index.html`

**공사관리 — 준공 시 방문 자동 정리** (캘린더 요청 2번)
- 현장을 **준공으로 바꾸면** 그 현장의 **오늘 이후·아직 안 다녀온 ‘정기 방문’ 일정을 자동 삭제** (과거·다녀온 기록은 보존)
