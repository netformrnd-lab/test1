# 감리 체크리스트(inspect) 교체·수정 시 주의

`app/inspect/index.html` 은 **디자인/체크리스트 내용**과 **앱 연동 기능**이 한 파일에 같이 있어요.
디자이너가 준 새 HTML로 **통째로 교체**하면, 연동 기능이 **같이 사라져서** 아래가 전부 깨집니다:

- Supabase 연결 (→ "연결 오류 — 앱에서 열어주세요")
- 대시보드로 감리일지 전송
- 담당 감리원 자동 채움 (감리원·공사감리자)
- 잔디 알림
- 서버 기준 회차(제N차)
- 모바일 확대 잠금 · 팝업 가림 수정

## ✅ 권장: "통째 교체" 대신 "내용만 수정"

제일 안전한 방법은 **저장소에서 Claude Code로 내용만 고치는 것**이에요
(파일을 바꾸지 말고, "○○ 항목 추가/수정해줘" 식으로). 그러면 연동이 안 사라져요.

디자이너가 **standalone HTML**을 준다면, 통째로 덮지 말고
그 파일을 Claude(또는 담당 개발자)에게 주고 **"내용만 합쳐달라"** 고 하세요.

## 🛟 자동 안전장치 (이미 적용됨)

`build-deploy.js` 가 빌드할 때 `inspect/index.html` 에 **핵심 연동이 들어있는지 검사**합니다.
하나라도 빠지면 **빌드가 중단**되고, 뭐가 빠졌는지 알려줘요 → **깨진 버전은 배포가 안 됩니다.**

검사하는 핵심 마커(이게 파일에 반드시 있어야 함):

| 마커 | 의미 |
|---|---|
| `@supabase/supabase-js` | Supabase 로드 `<script>` |
| `createClient` | Supabase 클라이언트 생성 |
| `sendToDashboard` | 대시보드 전송 연동 |
| `refreshServerRound` | 서버 기준 회차 |
| `report-photos` | 사진 업로드 |
| `maximum-scale=1` | 모바일 확대 잠금 |
| `env(safe-area-inset-bottom` | 팝업 모바일 가림 수정 |

> 교체 후 빌드가 중단되면, 위 항목이 새 파일에 빠진 거예요.
> 그 부분을 다시 넣거나, "내용만 수정" 방식으로 바꾸면 됩니다.
