# 팀허브를 우리 쪽으로 — 하실 일은 **파일 하나 복사**뿐입니다

브랜드허브 바로 옆에 팀허브를 둡니다. 공유폴더도, 드라이브 글자(Z:·Y:)도,
폴더 허락도 필요 없습니다.

```
/volume1/web/brand/
  ├ brand.html              ← 브랜드허브 (이미 있음)
  └ teamhub/
      ├ teamhub.php         ← 저절로 올라갑니다 (손댈 것 없음)
      ├ mediam_TeamHub.html ← ★ 이것만 사장님이 한 번 복사
      └ DB/                 ← 저절로 만들어집니다
          ├ 미디어마케팅팀/   ← 팀허브 자료
          ├ 백업/
          └ 주고받기/        ← 할 일이 오가는 자리
```

---

## 하실 일 — 딱 하나

받으신 **`선택_NAS…v2.5.9.zip`** 을 풀면 `teamhub` 폴더 안에
`mediam_TeamHub.html` 이 있습니다. 그 파일을 NAS 의 이 자리에 넣으세요.

```
web  →  brand  →  teamhub      (teamhub 폴더가 없으면 만드세요)
```

File Station 으로 끌어다 놓으면 됩니다. 25MB 라 조금 걸립니다.

> `teamhub.php` 는 **넣지 않으셔도 됩니다** — 브랜드허브가 저절로
> 받아다 둡니다 (자동 업데이트 목록에 넣어 뒀습니다).

---

## 되는지 보기

주소창에 이것만 쳐 보세요.

```
https://netformrnd.synology.me/brand/teamhub/teamhub.php
```

이렇게 나오면 끝입니다.

```json
{"ok":true,"app":"teamhub-nas","label":"브랜드허브 · 미디어마케팅팀","writable":true, …}
```

| 이렇게 나오면 | 뜻 |
|---|---|
| `writable: true` | 다 됐습니다 ✅ |
| PHP 글자가 그대로 | Web Station 의 PHP 가 꺼져 있습니다 |
| `writable: false` | `web/brand/teamhub` 폴더에 쓰기 권한이 없습니다 |
| 404 | 아직 `teamhub.php` 가 안 올라왔습니다 (자동 업데이트를 한 번 기다리거나, 이 폴더의 것을 직접 넣으세요) |

그다음 브랜드허브를 `Ctrl+Shift+R` 로 새로 고치면, 할 일 연동 칸에
**「✅ 바로 옆 팀허브와 붙었습니다」** 가 뜹니다.

## 팀허브 열기

팀 허브 → 미디어마케팅팀 → `✎` → **자리** 를 이 주소로:

```
teamhub/mediam_TeamHub.html#/board
```

| 뒤에 붙이면 | 열리는 곳 |
|---|---|
| `#/board` | 할 일 |
| `#/calendar` | 팀 캘린더 |
| `#/today` | TODAY |

## 할 일은 저절로 오갑니다

- 팀허브가 내보낸 할 일 → 브랜드허브가 **날짜 폴더 안까지 찾아** 가져옵니다
- 우리 할 일 → **`주고받기`** 에 놓이고, 팀허브 `[불러오기]` 가 집어 갑니다
- 같은 일은 **같은 번호로 이어지고**, 양쪽이 고친 칸은 **칸마다 합쳐집니다**

## ⚠️ 한 가지만 봐 주세요 — 자료가 주소로 새지 않게

자료(`DB` 폴더)가 웹 폴더 안에 있어서, **주소를 아는 사람은 로그인 없이도
그 파일을 받아 갈 수 있습니다.** `teamhub.php` 가 `.htaccess` 로 막아 두지만
그건 **Apache 일 때만** 듣습니다.

DSM → **웹 스테이션** → 웹 서비스(브랜드허브) → **일반 설정** 에서
**HTTP 백엔드 서버**를 보세요.

- **Apache** 면 → 그대로 두셔도 됩니다
- **Nginx** 면 → 같은 화면의 `사용자 정의 설정`(또는 역방향 프록시 규칙)에
  아래 한 토막을 넣어 주세요

```nginx
location ~ ^/brand/teamhub/DB/ { deny all; return 404; }
```

넣기 어려우시면 알려 주세요 — 자료만 웹 폴더 **밖**으로 빼는 길도 있습니다
(`teamhub.php` 맨 위 `$BASE` 한 줄만 고치면 됩니다).
