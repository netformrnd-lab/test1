# 하나의 프로그램 — 화면만 둘, 자리는 한 곳

브랜드허브와 미디어마케팅팀 팀허브가 **같은 자리**를 씁니다.
쓰는 사람에게는 프로그램 하나이고, **화면만 따로 떼어** 둔 것입니다.

```
웹 (NAS 가 내보내는 주소)
  /brand/brand.html          ← 브랜드허브
  /teamhub/mediam_TeamHub.html  ← 팀허브 (미디어마케팅팀 누르면 열림)
  /teamhub/teamhub.php          ← 팀허브가 NAS 폴더를 읽고 쓰는 다리

자리 (공유폴더 — 한 곳)
  Z:\넷폼알앤디 공유폴더\브랜드허브\
    ├ DB_미디어마케팅팀\   ← 팀허브가 읽고 쓰는 자리
    ├ DB_backup\           ← 2중 저장
    └ 주고받기\             ← 할 일이 오가는 자리
```

할 일은 **양방향**입니다 — 브랜드허브가 `주고받기` 에 우리 할 일을 놓고,
팀허브 `[불러오기]` 가 집어 갑니다. 팀허브가 `DB_미디어마케팅팀` 에
내보내면 브랜드허브가 저절로 읽어 옵니다.

---

## 한 번만 하면 됩니다

### ① 자리 만들기
File Station 에서 **`넷폼알앤디 공유폴더`** 안에 **`브랜드허브`** 폴더를
만들고, 그 안에 셋을 만듭니다.

```
DB_미디어마케팅팀    DB_backup    주고받기
```

쓰던 자료가 있으면 `00. 미디어마케팅팀\미디어마케팅팀 브랜드허브\DB_미디어마케팅팀 브랜드허브`
안의 것을 **`DB_미디어마케팅팀` 으로 통째로 옮깁니다.**
(옮기기 전에 그 폴더를 한 벌 복사해 두세요.)

> 아직 안 옮기셔도 됩니다 — 브랜드허브는 **옛 자리도 같이 찾습니다.**

### ② Web Station · PHP 켜기
DSM → 패키지 센터 → **Web Station** → PHP 프로필 **7.4 이상**.
(브랜드허브가 돌고 있으면 이미 켜져 있습니다.)

### ③ 파일 두 개 넣기
`web` 공유폴더 안에 **`teamhub`** 폴더를 만들고 넣습니다. 이름 그대로.

| 파일 | 어디서 |
|---|---|
| `mediam_TeamHub.html` | 받으신 `선택_NAS…v2.5.9.zip` 안 (25MB) |
| `teamhub.php` | **이 폴더의 것** |

### ④ 자리 확인
`teamhub.php` 맨 위 **한 줄**만 보면 됩니다.

```php
$BASE = '/volume1/넷폼알앤디 공유폴더/브랜드허브';
```

아래 셋이 다 여기를 따라갑니다. `/volume1` 이 맞는지는 File Station →
그 폴더 → 속성에서 봅니다.

### ⑤ 🔑 열쇠 (바깥에서도 열려면 꼭)
`teamhub.php` 는 **열쇠가 없으면 사무실 안에서만** 열립니다.
`teamhub` 폴더에 **`teamhub-key.txt`** 를 만들고 긴 글자 한 줄:

```
nf-7Gq2-Zx91-aL44-머리아픈글자
```

> 저장소가 공개라 `teamhub.php` 안에는 적지 마세요. 이 파일은 깃허브에
> 안 올라갑니다.

### ⑥ 권한
File Station → `브랜드허브` 폴더 → 속성 → 권한에 **`http`** 계정 추가
(**읽기/쓰기**, 하위 폴더에 적용).

### ⑦ 되는지 보기

```
https://netformrnd.synology.me/teamhub/teamhub.php
```

이렇게 나오면 끝입니다 — `writable: true` 가 중요합니다.

```json
{"ok":true,"app":"teamhub-nas","v":2,"label":"브랜드허브 · 미디어마케팅팀","writable":true, …}
```

| 이렇게 나오면 | 할 일 |
|---|---|
| PHP 글자가 그대로 | PHP 가 꺼져 있음 → ② |
| `사무실 밖에서는 열 수 없습니다` | 열쇠를 안 정함 → ⑤ |
| `팀 폴더를 찾을 수 없습니다` | `$BASE` 가 틀림 → ④ |
| `writable: false` | 권한 → ⑥ |

## 브랜드허브에 걸기

팀 허브 → 미디어마케팅팀 → `✎` → **자리** 를 이 주소로:

```
https://netformrnd.synology.me/teamhub/mediam_TeamHub.html#/board
```

| 뒤에 붙이면 | 열리는 곳 |
|---|---|
| `#/board` | 할 일 |
| `#/calendar` | 팀 캘린더 |
| `#/today` | TODAY |
| `#/contents` | 공정 칸반 |

---

## 판이 올라오면

**`mediam_TeamHub.html` 하나만** 새 파일로 바꿔 넣습니다.
`teamhub.php` 도, 링크도, 자리도 그대로입니다.

공유폴더에서 새 판을 찾아 헤맬 일이 없어집니다 — 주소 하나로 끝입니다.
