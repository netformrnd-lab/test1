# 미디어마케팅팀 허브를 우리 NAS 에 올리기

그쪽 프로그램을 **우리 NAS 웹 폴더에 그대로 두고**, 브랜드허브에서 링크로
엽니다. PC 에 설치할 것은 없습니다. 할 일은 그대로 양방향으로 오갑니다.

---

## 한 번만 하면 됩니다 (10분)

### ① Web Station · PHP 켜기
DSM → 패키지 센터 → **Web Station** → PHP 프로필 **7.4 이상**.
(이미 브랜드허브가 돌고 있으면 켜져 있습니다.)

### ② 파일 두 개 넣기
`web` 공유폴더 안에 **`teamhub`** 폴더를 만들고 두 개를 넣습니다.

| 파일 | 어디서 |
|---|---|
| `mediam_TeamHub.html` | 받으신 `선택_NAS…v2.5.9.zip` 안에 있습니다 (25MB) |
| `teamhub.php` | **이 폴더의 것** (자리를 미리 적어 뒀습니다) |

이름을 바꾸면 안 됩니다.

### ③ 자리 확인
`teamhub.php` 맨 위에 이렇게 적어 뒀습니다 — NAS 안 경로가 다르면 고칩니다.

```php
$TEAM_DIR   = '/volume1/넷폼알앤디 공유폴더/00. 미디어마케팅팀/미디어마케팅팀 브랜드허브/DB_미디어마케팅팀 브랜드허브';
$MIRROR_DIR = '/volume1/…/DB_backup';
$COPY_DIR   = '/volume1/…/DB_Copy';
```

> `/volume1` 이 맞는지는 File Station 에서 그 폴더 → 속성으로 봅니다.

### ④ 🔑 열쇠 정하기 (바깥에서도 열려면 꼭)
`teamhub.php` 는 **열쇠가 없으면 사무실 안에서만** 열립니다. 집에서도
열려면 `teamhub` 폴더에 **`teamhub-key.txt`** 를 만들고 길고 어려운 글자를
한 줄 적습니다.

```
nf-7Gq2-Zx91-aL44-머리아픈글자
```

> 이 파일은 깃허브에 안 올라갑니다. `teamhub.php` 안에 직접 적지 마세요 —
> 저장소가 공개라 아무나 보게 됩니다.

### ⑤ 권한
File Station → 그 세 폴더 → 속성 → 권한에 **`http`** 계정 추가
(메인·백업은 **읽기/쓰기**, `DB_Copy` 는 **읽기**).

### ⑥ 되는지 보기
브라우저로 열어 봅니다.

```
https://netformrnd.synology.me/teamhub/teamhub.php
```

이렇게 나오면 끝입니다 — `writable: true` 가 중요합니다.

```json
{"ok":true,"app":"teamhub-nas","v":2,"label":"미디어마케팅팀 브랜드허브 DB","writable":true, …}
```

- PHP 글자가 그대로 보이면 → PHP 가 꺼져 있습니다 (①)
- `사무실 밖에서는 열 수 없습니다` → 열쇠를 안 정했습니다 (④)
- `팀 폴더를 찾을 수 없습니다` → 자리가 틀렸습니다 (③)

## 브랜드허브에 걸기

팀 허브 → 미디어마케팅팀 → `✎` → **자리** 를 이 주소로 바꿉니다.

```
https://netformrnd.synology.me/teamhub/mediam_TeamHub.html
```

열쇠를 정했으면 처음 한 번 그 화면에서 열쇠를 넣습니다.

**바로 할 일로 열고 싶으면** 뒤에 `#/board` 를 붙입니다.

| 어디 | 주소 뒤에 |
|---|---|
| 할 일 | `#/board` |
| 팀 캘린더 | `#/calendar` |
| TODAY | `#/today` |
| 공정 칸반 | `#/contents` |

## 판이 올라오면

**`mediam_TeamHub.html` 하나만 새 파일로 바꿔 넣습니다.**
`teamhub.php` 도, 링크도, DB 도 그대로입니다. (그쪽 설명서에
「DB 구조 변경 없음」 이라고 매 판마다 적혀 있습니다.)

더는 공유폴더에서 새 판을 찾아 헤맬 일이 없습니다 — 주소 하나로 끝입니다.
