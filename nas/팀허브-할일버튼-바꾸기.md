# 팀허브 「할 일」 버튼만 우리 프로그램으로 — 파일 편집 없이

미디어마케팅팀 팀허브에서 **왼쪽 「할 일」** 을 누를 때만 우리 브랜드허브
할 일 화면이 열립니다. **캘린더·콘텐츠·TODAY 같은 나머지 버튼은 그대로**.
`mediam_TeamHub.html` 은 **한 글자도 안 건드립니다.**

## 하실 일 — 주소만 바꾸면 끝

미디어마케팅팀이 쓰는 주소를 이걸로 바꾸세요 (북마크·링크):

```
전:  https://netformrnd.synology.me/brand/mediam_TeamHub.html
후:  https://netformrnd.synology.me/brand/mediam.php
```

`mediam.php` 가 팀허브를 **그대로** 불러주면서, 「할 일」 버튼을 우리로
보내는 한 줄을 **저절로 끼워** 줍니다. File Station 에서 편집할 것도,
파일을 내려받을 것도 없습니다.

> `mediam.php` · `th-hook.js` 는 자동 업데이트 목록에 넣어 뒀습니다.
> `save.php?action=bootstrap` 한 번 열면 NAS 에 올라옵니다.

## 되는지 보기

1. `https://netformrnd.synology.me/brand/mediam.php` 열기
2. 팀허브가 평소처럼 뜹니다 (아이디로 로그인)
3. 왼쪽 **「할 일」** 클릭 → 우리 할 일 화면이 열리면 성공 ✅
4. HOME·캘린더·콘텐츠 등은 전처럼 팀허브 안에서 열립니다

## 브랜드 허브 쪽 (팀 허브 목록)

이미 v69 에서 「할 일」 은 우리 화면으로 가게 돼 있습니다. 미디어마케팅팀
자리를 `✎` 로 열어 자리를 `mediam.php` 로 바꿔 두면, 캘린더·TODAY 로 들어갈
때도 이 끼워넣기가 적용됩니다.

## 되돌리기

주소를 다시 `mediam_TeamHub.html` 로 쓰면 원래대로입니다.
(`mediam.php` 는 원본을 전혀 바꾸지 않습니다.)

## 참고 — 할 일은 각자 브랜드허브 계정으로

「할 일」 을 누르면 우리 브랜드허브로 갑니다. 미디어마케팅팀도 **각자
브랜드허브 계정으로 로그인**하면 「팀 멤버별 오늘 할 일」 에서 본인 카드가
보입니다. 계정이 없으면 관리자가 [관리] 에서 추가해 주세요.
