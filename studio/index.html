제작 현황

영상 한 편이 카드 한 장입니다. 카드를 누르면 그 영상의 기획으로 들어갑니다.

진행 보드

크레딧

제작 탭에서 영상 길이를 적으면 여기서 차감됩니다

헤이젠 요금제 화면의 숫자를 그대로 넣으세요.

기획

헤이젠에 넣을 프롬프트

칸을 누르면 전체가 선택됩니다. 그 상태에서 Ctrl+C (맥 ⌘C).

검수 2단계

1차는 사실과 규정, 2차는 연출과 리듬 — 서로 다른 눈으로

제작

프롬프트를 헤이젠에 넣고, 나온 영상의 길이와 링크를 적어 두세요.

완료

발행한 영상과 실제로 쓴 크레딧.

자료

여기 있는 내용만 영상에 쓰입니다. 검수할 때도 그대로 전달됩니다.

API 키

이 PC 안에만 저장됩니다. 화면에는 끝 네 자리만 보입니다
헤이젠 주소가 안 맞을 때

제작 버튼에서 HTTP 404 나 400 이 뜨면, 새 탭에서 주소 확인 을 열어 200 이나 400 이 뜬 줄의 주소를 아래에 넣고 제작실을 껐다 켜세요.

직접 넣은 자료

검수에서 나온 지적도 “지식으로 저장”을 누르면 여기 쌓입니다
