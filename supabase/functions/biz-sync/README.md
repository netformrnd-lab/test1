# biz-sync — 경영지원팀 업무관리(세금계산서) 시스템 연동 Edge Function

운영본부 콘솔(미수금 관리)과 경영지원팀 업무관리 시스템(sq-biz · Firebase Firestore)을 **10분마다** 맞춥니다.
콘솔(브라우저)은 그쪽 DB에 직접 붙지 않고, 이 함수만 서비스 계정 키를 씁니다(키가 브라우저에 노출되지 않음).

## 하는 일

| 방향 | 내용 | 그쪽 데이터 |
| --- | --- | --- |
| 읽기 | 그쪽 계약 목록을 `public.biz_contracts` 에 캐시 → 콘솔 "경영지원 연동" 패널에서 계약 연결에 사용 | contracts (읽기) |
| 읽기 | 연동 계약 건 중 단지명이 **정확히 하나만** 일치하면 그쪽 계약과 자동 연결 (애매하면 사람이 패널에서 고름) | contracts (읽기) |
| 읽기 | 연결된 발행 요청의 상태(요청/검토중/발행완료/반려/취소/보류) · 발행일 · 발행금액 · 매칭된 입금(날짜·금액) → `receivable_items` | taxInvoiceRequests, deposits (읽기) |
| 쓰기 | 콘솔에서 "청구 요청"한 항목(`biz_push='pending'`) → 그쪽 **발행 요청 생성** (+ 그쪽에 계약이 없으면 계약 생성, 첫 요청에만 사업자등록증 첨부, 감사로그 1줄) | taxInvoiceRequests, contracts, _blobs, documents, auditLog (생성만) |

- 기존 요청·계약의 **수정 · 삭제 · 상태 변경은 하지 않습니다.** (phase 에 요청 id 를 연결하는 것만 예외)
- 콘솔에서 사람이 직접 입력한 발행일·입금은 덮어쓰지 않습니다(연동이 쓴 값만 갱신).
- 입금이 반영되면 계약 건 수금액 → 현장 수금액으로 합산됩니다(콘솔과 같은 규칙).
- 모든 동작은 `public.biz_sync_log` 에 남고, 콘솔 "경영지원 연동" 패널에서 최근 30건을 봅니다.

## 배포 순서

1. **DB**: Supabase SQL Editor 에서 `backend/migration-biz-sync.sql` 실행 (거래처·연동 칸·캐시·로그·버킷)
2. **함수 배포**
   - CLI: `supabase functions deploy biz-sync`
   - 대시보드: Edge Functions → Deploy a new function → 이름 `biz-sync` → `index.ts` 와 `lib.ts` 두 파일 모두 붙여넣기
3. **비밀값** (Project Settings → Edge Functions → Secrets, 또는 CLI `supabase secrets set`)

   | 이름 | 값 |
   | --- | --- |
   | `BIZ_SA_JSON` | 경영지원팀이 USB 로 준 서비스 계정 키 **JSON 파일 내용 전체**. 파일을 USB 에서 바로 열어 내용을 복사해 붙여넣고, PC 에 저장하지 않습니다. |
   | `BIZ_SYNC_SECRET` | 아무 긴 임의 문자열(예: 비밀번호 생성기 40자). 아래 pg_cron 에 같은 값을 넣습니다. |
   | `BIZ_PILOT_PREFIX` | (선택) 기본 `[시범] `. 정식 전환 때 빈 값으로 바꿉니다. |
   | `BIZ_DRY_RUN` | (선택) `1` 이면 그쪽에 아무것도 쓰지 않고 로그만. 첫 점검 때 켰다가 끕니다. |

4. **첫 점검**: 콘솔 → 미수금 관리 → "경영지원 연동" → **지금 동기화**. 로그에 "그쪽 계약 N건 읽음"이 보이면 읽기 연결 완료.
5. **10분 주기**: `backend/migration-biz-sync.sql` 8) 의 pg_cron 블록을 실행(Extensions 에서 pg_cron · pg_net 켜기, vault 에 비밀값 저장).

## 콘솔에서 쓰는 법

1. 미수금 관리 → **거래처 명부** → 거래처 추가(사업자등록증 상 정식 상호 · 사업자번호 · 대표자 · 이메일 · 주소 · 업태 · 종목 · 사업자등록증 파일)
2. 공사관리 → 현장 → 계약 건 수정 → **거래처 선택** + **"경영지원팀 세금계산서 시스템과 연동"** 체크 (시범 현장: 영통SK뷰아파트 · 태전e편한세상아파트)
3. 미수금 관리 → 현장 → **청구 요청** → 구분(계약금 / 중도금 / 잔금 / 계약금+잔금 한 번에) → 요청일 → 청구 요청
4. 10분 안에 그쪽 요청 목록에 `[시범] 현장명 …` 요청이 생기고, 항목 카드의 "경영지원 시스템" 줄에 요청번호(TIR-…)와 상태가 보입니다.
5. 경영지원팀이 발행완료 → 발행일이 자동 기록. 입금 매칭 → 입금일·금액 자동 기록, 회수 알림 종료.

## 안전장치 · 문제 해결

- 키가 없거나 틀리면 함수는 아무것도 쓰지 않고 로그만 남깁니다(콘솔은 "함수 배포·키 등록 전이면 정상").
- 거래처 미지정 · 금액 0원 · 파일 오류는 해당 항목만 `전송 오류`로 표시되고 다른 항목은 계속 진행합니다. 원인을 고친 뒤 항목 카드의 **다시 전송**.
- 경영지원팀이 콘솔에서 서비스 계정을 삭제하면 다음 실행부터 토큰 발급이 실패하고 연동이 멈춥니다(로그 `동기화 중단`).
- 로컬 로직 테스트: `node --experimental-strip-types supabase/functions/biz-sync/lib.test.mjs`
