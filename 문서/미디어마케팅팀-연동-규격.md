# 미디어마케팅팀 TeamHub 와 주고받는 규격

**근거: 그쪽이 준 `teamhub.php` · `읽어보기.txt` (v2.5.9) · 변경요약 문서.**
짐작이 아니라 그쪽 설명서에 적힌 그대로입니다.

---

## 1. 그쪽 DB 는 파일입니다 (데이터베이스 서버가 아닙니다)

`teamhub.php` 는 NAS 웹 폴더에 두는 **작은 파일 다리**입니다. 브라우저 대신
NAS 가 팀 폴더를 읽고 씁니다.

| op | 하는 일 |
|---|---|
| `ping` | 폴더 이름 · 쓸 수 있나 · 판 번호 |
| `list` `read` `stat` | 읽기 |
| `write` `remove` `mkdir` `move` | 쓰기 |

- 열쇠: `X-TeamHub-Key` 머리말 또는 `?k=`.
  `$ACCESS_KEY` 가 비어 있으면 **사무실 안(사설 IP)에서만** 열립니다.
- `?area=` 로 폴더가 갈립니다 — `team`(기본) · `mirror` · `copy`(**읽기만**).

---

## 2. 폴더 셋

| 이름 | 자리 | 무엇 |
|---|---|---|
| 메인 | `…\00. 미디어마케팅팀\미디어마케팅팀 브랜드허브\DB_미디어마케팅팀 브랜드허브` | 팀 DB · **그쪽이 내보내는 곳** |
| 백업 | `…\DB_backup` | 2중 저장 |
| **DB_Copy** | `…\DB_Copy` | **그쪽 [불러오기] 가 보는 곳 — 우리가 올리는 자리** |

---

## 3. 주고받는 파일

### 그쪽 → 우리 (받기)

```
…\DB_미디어마케팅팀 브랜드허브\2026-10-19\미디어마케팅팀-할일_2026-10-19.json
```

- v2.5.9 부터 **메인 폴더**입니다 (2.5.6~2.5.8 은 `DB_backup`).
- **날짜 폴더 안**에, 이름 뒤에 **날짜가 붙습니다.**
  → 우리는 세 단계까지 훑고, `미디어마케팅팀-할일` 로 시작하면 같은 것으로 봅니다.

### 우리 → 그쪽 (올리기)

```
…\DB_Copy\브랜드마케팅팀-할일.json   (+ .csv)
```

- 그쪽 규칙: **「DB_Copy 에서 이름에 "할일" 이 든 가장 최근 파일」**.
- 메인 폴더에 두면 **그쪽은 쳐다보지도 않습니다.**

### 모양 — 둘 다 같습니다

```json
{ "팀": "…", "내보낸때": "…", "줄수": 0,
  "할일": [ { "id":"", "브랜드":"", "업무명":"", "담당자":"", "상태":"",
             "기한":"", "진척률":0, "메모":"", "갈래":"", "고친때":"" } ] }
```

읽어보기 v2.5.8 에 **「브랜드 허브 할 일 내보내기 파일과 똑같은 모양」** 이라고
적혀 있습니다 — 그쪽이 우리 것을 보고 맞춰 둔 것입니다.

> ⚠️ `제목(title)` · `담당(assignee_id)` 같은 머리말은 그쪽이 **엑셀로 내보낼 때**
> 쓰는 것입니다. 주고받기용이 아닙니다.

---

## 4. 양쪽이 같은 줄을 고쳤을 때

그쪽도 우리와 같은 규칙입니다 — 읽어보기 v2.5.8:

> 같은 할 일은 같은 `id` 로 이어짐 · 다시 주고받아도 겹치지 않음 ·
> **양쪽에서 고친 칸은 칸마다 맞춤**

우리 쪽도 같습니다 (`mergeItem`) — 한 사람만 고친 칸은 그대로 살고, 둘 다
고친 칸은 나중에 고친 쪽, 글은 둘 다 남깁니다.

---

## 5. 통째로 맞추기 (할 일 말고 전부)

그쪽 [🔄 브랜드 허브 동기화] 차례 —

1. 브랜드허브 오른쪽 위 **📤** → 파일 받기
2. TeamHub 에서 그 파일 고르고 **[동기화 실행]**
3. 받은 파일을 브랜드허브 **📥** 로 넣기 (TeamHub 에서 바뀐 것이 있을 때만)

- 그쪽은 우리 파일을 **`schema === 2` 이고 `brands` 가 있는 것**으로 알아봅니다.
- **`.json` 만** 받습니다.
- 3번은 덮어쓰기라서, 우리 쪽은 그 직전에
  `브랜드허브_되돌리기용_날짜_시각.json` 을 한 벌 받아 둡니다.
