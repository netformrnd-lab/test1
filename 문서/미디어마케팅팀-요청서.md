# 미디어마케팅팀 TeamHub 담당자께 — 할 일 자동 연동 요청

브랜드마케팅팀 브랜드허브와 TeamHub 사이에 **할 일이 자동으로 오가게** 하고 싶습니다.
두 프로그램 모두 **이미 필요한 기능을 갖고 있어서**, 자동으로 돌게만 해 주시면 됩니다.

---

## 지금 상태

| | 됩니까 | 어떻게 |
|---|---|---|
| TeamHub → 브랜드허브 | △ | 사람이 **[내보내기]** 를 눌러야 파일이 생깁니다 (마지막 내보낸 것이 10/16 자였습니다) |
| 브랜드허브 → TeamHub | △ | 파일은 올려 두는데, 사람이 **[불러오기]** 를 눌러야 들어갑니다 |

**둘 다 사람 손이 한 번씩 가야 해서, 실제로는 안 돌아갑니다.**

---

## 부탁드리는 것 — 두 줄입니다

### ① 자동 내보내기

할 일이 **바뀔 때마다**(또는 5~10분마다) 아래 한 곳에 덮어써 주세요.

```
<팀 DB 폴더>/브랜드허브-주고받기/미디어마케팅팀-할일.json
```

- **날짜 폴더 없이, 늘 같은 이름**으로 덮어쓰기 — 저희가 「가장 새 파일 찾기」 를 안 해도 되게
- 모양은 **지금 [내보내기] 가 만드는 것 그대로**면 됩니다

### ② 자동 불러오기

같은 폴더에 저희가 올려 두는 이 파일을, **새 것이 보이면 저절로** 읽어 주세요.

```
<팀 DB 폴더>/브랜드허브-주고받기/브랜드마케팅팀-할일.json
```

- 지금 **[불러오기]** 가 하는 일과 똑같습니다 — 누르는 것만 없애 주시면 됩니다
- 저희는 **바뀔 때마다 바로** 이 파일을 덮어씁니다

## 파일 모양 (양쪽 같습니다)

```json
{
  "팀": "미디어마케팅팀",
  "내보낸때": "2026-10-19T05:00:00.000Z",
  "줄수": 23,
  "할일": [
    {
      "id": "mz1",
      "브랜드": "유튜브",
      "업무명": "쇼츠 10편 기획",
      "담당자": "최상기",
      "상태": "진행 중",
      "기한": "2026-10-27",
      "진척률": 40,
      "메모": "콘티 초안",
      "갈래": "할 일",
      "고친때": "2026-10-19T04:12:00.000Z"
    }
  ]
}
```

### ⚠️ 두 가지만 꼭 지켜 주세요

**1. `담당자` 는 번호가 아니라 <<이름>> 으로**

지금 내부 자료에는 `assignee_id: 2005` 처럼 번호로 들어 있습니다.
번호만 오면 저희 쪽에서는 **아무 사람에게도 안 붙습니다.**
내보내실 때 `users` 표를 참고해 **이름(예: `최상기`)** 으로 바꿔 주세요.

**2. 담당자가 비어 있으면, 그 줄을 맡은 사람 이름을 넣어 주세요**

프로젝트처럼 `assignee_id` 가 비어 있는 줄이 있습니다.
그런 줄은 저희 화면에서 **「공용(맡은 사람 없음)」** 으로 빠집니다.
TeamHub 화면에서 **누구 카드 밑에 보이는지** — 그 사람 이름을 넣어 주시면 됩니다.

## 같은 할 일을 양쪽이 고쳤을 때

- `id` 가 같으면 **같은 할 일**로 봅니다 (저희 쪽도 같은 규칙입니다)
- 칸마다 **`고친때` 가 나중인 쪽**을 씁니다
- 글(메모)은 **양쪽 다 남깁니다**

읽어보기 v2.5.8 에 적어 두신 규칙과 같습니다 — 새로 만드실 것이 없습니다.

## 폴더 자리

NAS 웹 폴더에 올려 둔 `teamhub.php` 를 쓰시면, 아래 한 곳으로 통합됩니다.

```
/web/brand/DB_teamhub/주고받기/
    ├ 미디어마케팅팀-할일.json     ← 그쪽이 덮어쓰기
    └ 브랜드마케팅팀-할일.json     ← 저희가 덮어쓰기
```

`teamhub.php?op=write&area=copy&p=…` 로 바로 쓰실 수 있고,
읽기는 `?op=read&area=copy&p=…` 입니다. (사내망 안에서만 열립니다)
