# 넷폼알앤디 브랜드 허브 — 개발 여정 기록

> 2026-08-31 첫 대시보드부터 2026-10-22 오늘까지, 우리가 함께 만들어온 길.
> `brand.html` 한 파일(+ NAS의 PHP 도구들)로 흩어져 있던 팀 자료를 한곳에 모으는 여정이었습니다.
> 이 문서는 기록용입니다. 허브 화면(brand.html)에는 넣지 않았습니다.

---

## 한눈에 보는 큰 줄기

1. **지표 대시보드 → 브랜드 허브** — "흩어진 팀 자료를 한곳에"가 처음부터 끝까지의 목적.
2. **NAS에 올려서 같이 쓰기** — 시놀로지 NAS + PHP로 저장, 여러 명이 동시에 써도 안 꼬이게.
3. **자료·문의·채널** — NAS 자료함, 구글시트 문의, 브랜드 채널 모으기.
4. **브랜드 소개·온보딩·브랜드북** — 신입이 읽는 화면, 올린 문서를 그대로 펴 보기.
5. **할 일·업무일지·프로젝트** — 팀 KPI, 루틴, 프로젝트 칸반, 업무일지.
6. **내부계정 금고 · 마케팅 비용** — 엑셀 정리·잠금, 결제 만료 알림.
7. **미디어마케팅팀 연동 → 이식** — 팀허브와 할 일 주고받기, 끝내 우리 안으로.
8. **미디어마케팅 업무판** — 콘텐츠 제작 칸반·캘린더·채널·촬영·장비·미마 홈.
9. **팀 노하우(위키)** — "이거 어떻게 하더라"를 사진 단계로, PDF·HTML·ZIP에서 가져오기.
10. **안정화** — 동시편집 안전, 저장 안전장치, 전체 버그 점검.

## 단계별 여정

### 1단계. 시작 — 대시보드에서 허브로 (2026-08-31 ~ 09-01)
- 브랜드 대시보드를 만들고 NAS 공유 저장과 연동 준비.
- 시놀로지 NAS 확정, Web Station·PHP 설치 절차를 하나씩 문서화.
- 저장 위치 자동 판별, 저장 실패를 눈으로 진단, 폴더 권한 문제 안내.
- **지표 대시보드 → "브랜드 허브"로 전면 개편**: 숫자 보기에서 지식 관리 구조로.

### 2단계. 자료·문의·채널 (2026-09-01 ~ 09-02)
- NAS 자료함: 경로 복사, 파일 업로드·다운로드, 탐색기처럼 폴더 열기.
- 브랜드에 맞는 NAS 폴더가 저절로 붙게 (손으로 지정 불필요).
- 배포 파일 목록을 `manifest.txt`로 분리 — 새 파일이 자동 배포되게.
- 구글시트 문의 기록을 브랜드별로, 요약 중심으로, 연도별 추이 그래프까지.
- 📣 브랜드 채널(블로그·카페·유튜브) + 최근 발행, RSS 자동 최신화.
- 📖 문서 안의 내용으로 찾기 (워드·엑셀·PPT·PDF).

### 3단계. 같이 쓰기 — 협업과 안정 (2026-09-02 ~ 09-03)
- **여러 명이 동시에 써도 자료가 사라지지 않게** (칸별 합치기).
- 글 쓰는 중 화면이 흔들리거나 내용이 사라지지 않게.
- 새로고침 없이 실시간으로 같이 보기, 구글시트도 따라오게.
- 회의록 탭 + AI 정리, 달력 일정(담당자 포함), 되돌리기(Ctrl+Z).
- 마케팅 비용·브랜드북 첫 도입.

### 4단계. 로그인·AI·정리 도구 (2026-09-04 ~ 09-08)
- 로그인 / 퇴사자 차단.
- AI 도우미: 클로드·챗GPT·마누스 키, 사무실 PC AI, 키 없이 복사→붙여넣기.
- NAS 폴더에서 바로 정리(폴더 만들기·올리기·옮기기), 🪄 알아서 정리(확인·되돌리기).
- 무엇을 지우든 한 번은 휴지통으로.
- 근무현황 캘린더(우리 팀만), 휴대폰에서 쓸 만하게.
- 탭 합치기, 할 일을 업무로, 개인 그로스보드, 화이트보드.

### 5단계. 브랜드 소개·온보딩 (2026-09-08 ~ 09-19)
- 그로스보드를 여러 모양으로 다듬다 결국 접음 (브랜드플로우 백업도 옮겨봄).
- 브랜드 화면을 회사 연혁 라인으로, 기획서 양식으로.
- 🧭 온보딩 — 신입 첫날 화면, 문서를 넣으면 네 단이 자동으로.
- 소개를 인포(표·칩·카드)로, 조직도·해마다의 팀 목표를 연표로.

### 6단계. 브랜드북 — 올린 그대로 펴 보기 (2026-09-22 ~ 09-28)
- 한글 PDF가 진짜로 읽히게, 📗 브랜드북으로 통일(AI 없이).
- **올린 브랜드북(PDF/HTML)을 만든 그대로** 한 장씩 넘겨 보고, 두 번 눌러 고치기.
- 브랜드북 히스토리(누가·언제·무엇을), 🔔 브라우저 알림.
- (여기서 쓰던 pdf.js가 나중에 팀 노하우 PDF 가져오기에 다시 쓰임.)

### 7단계. 할 일·업무일지·프로젝트 (2026-09-30 ~ 10-16)
- ✅ 할 일을 "팀 KPI + 팀원별 오늘"로, 🔄 루틴·🚀 프로젝트·⚠️ 더딘 업무.
- 📓 업무일지(끝낸 일은 그날 하루만), 반기 보기, 프로젝트 칸.
- 프로젝트 밑에 보조 업무, 끝내는 것은 사람이 정함.
- 화면이 위로 튀던 것·퍼센트가 지워지던 것 등 여러 버그 정리.

### 8단계. 내부계정 금고 (2026-10-01 ~ 10-16)
- 🔐 내부계정: 엑셀을 붙여 넣으면/직접 읽어 AI가 정리.
- 🔒 따로 비밀번호로 진짜 잠금, 비밀번호 바꾸는 자리.
- 한 칸에 "아이디/패스워드" 같이 적힌 것 나누기, 겹친 줄 합치기.
- 비밀번호가 아이디로 나오던 버그를 여러 경로에서 추적·수정.

### 9단계. 마케팅 비용 (2026-10-13 ~ 10-14)
- 💳 "신청일 ~ 만료일", 결제 만료를 홈에서 크게, 결제 일주일 전 알림.
- 2년 주기 등 주기를 직접 적기, AI 비용을 한곳에 모아 보기.

### 10단계. 미디어마케팅팀 연동 → 이식 (2026-10-14 ~ 10-20)
- 미디어마케팅팀 "팀허브"와 **할 일 양방향 주고받기** (공유폴더 → 서버 → DB 직접).
- 저쪽이 브라우저 속 Postgres였음을 알아내고, 끝내 **할 일 버튼만 우리 프로그램으로 이식**(`th-hook.js`, `mediam.php`).
- 중간에 자료가 사라지던 심각한 합치기 버그를 잡음.

### 11단계. 미디어마케팅 업무판 (2026-10-21 ~ 10-22)
- 🎬 미디어마케팅 탭 신설 (TeamHub 메뉴 이식) + TeamHub 스킨.
- **콘텐츠 제작 칸반**(기획·촬영·편집·검수·배포·완료, 성과 조회수·좋아요), **드래그로 단계 이동**.
- **콘텐츠 캘린더**(내 것만 보기) ↔ 우리 달력 양방향 연동.
- 팀 관리(추가·이름·이동), 사람 관리에서 팀 선택.
- **미마 홈을 타일 위주로**: 전체 현황 · 🙋 내 업무(로그인한 사람마다 다르게) · 팀별 · 채널.
- **촬영과 장비를 별도 탭으로 분리** (🎥 촬영 / 🎒 장비).

### 12단계. 팀 노하우 — 위키 (2026-10-21 ~ 10-22)
- 📖 팀 노하우: "이거 어떻게 하더라"(명함제작·홈페이지 수정·전자결재 등)를 한곳에.
- **사진 + 아래 설명**을 순서대로, 한 단계에 사진 여러 장, 읽기 화면을 번호 타임라인으로.
- 글은 크게·사진은 작은 썸네일(누르면 크게), 노하우/분류/메뉴 이름 바꾸기.
- **PDF 올리면 쪽마다 한 단계**로, **HTML 가이드 올리면 글·사진 그대로** 단계로.
- **HTML + 사진(ZIP) 같이 올리면** 각 단계에 전체 원본 사진이 들어가게 (브라우저에서 바로 압축 해제).
- 자동 매칭이 어긋날 때: 사진을 ⇡/⇣단계로 옮기거나 **🖼 사진 고르기**로 번호 지정.
- PDF·HTML로 만든 노하우가 수정 때 튕기던 버그(id 깨짐) 수정.

### 13단계. 안정화 — 전체 점검 (2026-10-22)
- 모든 화면·동작 JS 오류 0건 확인.
- 드래그는 이동만 (카드가 지워지지 않음).
- 저장 실패 안전장치 보강 — 사진이 많아 브라우저 임시 저장이 가득 차도 안 터지게.

## 함께 지켜온 원칙
- **흩어진 자료를 한곳에** — 새 기능은 늘 이 목적에서 파생.
- **여럿이 같이 써도 안 꼬이게** — 동시편집·합치기·휴지통·되돌리기.
- **인터넷 없이도** — NAS는 잠근 채, 브라우저 안에서 처리(pdf.js·ZIP 해제 등).
- **올린 그대로** — 문서·사진을 다시 압축해 망가뜨리지 않게.
- **누구나 바로** — 어려운 설정 없이, 보이는 대로 눌러서.

## 기술 메모 (나중에 참고)
- 한 파일 `brand.html`(≈2MB) + NAS PHP 도구들(`save.php`·`load.php`·`guard.php`·`auth.php`·`files.php`·`mediam.php`·`teamhub.php`·`th-hook.js` 등).
- 데이터는 NAS `data/brand-data.php`에 JSON으로. `rev.txt`로 판 번호, 저장 시 칸별 합치기.
- 배포 목록은 `nas/manifest.txt`. 새 파일은 자동 배포. pdf.js(`pdf.min.js`·`pdf.worker.min.js`)도 함께 올라감.
- 버전 문자열 `APP_VER`가 화면 오른쪽 위에 표시 (예: v20261022-108).
- 저장소: `netformrnd-lab/test1` (PUBLIC) — 열쇠·비밀번호·API 키는 커밋 금지.
