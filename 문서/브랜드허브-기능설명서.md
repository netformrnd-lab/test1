# 2. 🏠 홈 — 전체 현황 한 장

## 무엇이 나오나

**맨 위 숫자 6개** — 지금 회사 상태를 한 줄로

| 숫자 | 뜻 |
|---|---|
| 문의 | 전체 문의 건수 · 이번 달 몇 건 |
| 한 달 비용 | 매달 나가는 돈 합계 · 올해 누적 |
| 브랜드 | 운영 중인 브랜드 수 |
| 남은 할 일 | 안 끝난 일 / 전체 |
| 자동화 | 돌고 있는 자동화 수 |
| 자료 | 올려둔 파일 수 |

**브랜드 카드** — 브랜드마다 문의·비용·자료 수가 한 장에. 이번 달 문의가 **▼50%** 처럼 늘고 준 것이 표시됩니다.

**공지사항** — 팀 전체에 알릴 것. 맨 위에 고정됩니다.

**기한 임박한 할 일** — 오늘·내일 마감인 것이 자동으로 올라옵니다.

**결제 만료 알림** — 구독료 결제 **일주일 전**에 크게 뜹니다.

> 💡 **쓰는 법:** 아침에 들어와서 이 화면만 보면 오늘 뭐가 급한지 다 보입니다. 따로 적을 것 없습니다 — 다른 화면에 적은 것이 저절로 모입니다.

# 3. ✅ 할 일 — 매일 쓰는 화면 ⭐

**이 화면이 핵심입니다.**

## 구성

**팀 → 사람 카드** 순서로 섭니다. 브랜드전략팀 / 콘텐츠마케팅팀 / 미디어마케팅팀.

사람 카드 하나에 **그 사람의 오늘**이 다 들어 있습니다.

### 카드 안의 세 칸

| 칸 | 무엇을 넣나 | 특징 |
|---|---|---|
| 🔁 **오늘 루틴** | 매일·매주 반복하는 일 | 체크만 하면 됩니다. 날마다 저절로 다시 뜹니다 |
| 📓 **업무일지** | 오늘 할 일 | **못 끝내면 다음 날로 저절로 넘어갑니다** |
| 🚀 **진행중 프로젝트** | 기간이 긴 일 | 진행률 %로 관리. 안에 체크 항목을 넣습니다 |

### 꼭 알아야 할 동작

- **끝낸 일은 그날 하루는 남습니다** — 체크하면 줄이 그어진 채로 그 자리에 있습니다. 뭘 했는지 보여야 하니까요. 다음 날 접힙니다.
- **못 끝낸 일은 내일로 넘어갑니다** — 따로 옮겨 적을 필요 없습니다.
- **진행률을 누르면 업무일지에 기록**됩니다 — 프로젝트를 얼마나 밀었는지가 일지에 남습니다.
- 동그라미(%) 는 **오늘 치**만 셉니다. 오늘 할 일이 없으면 `—`로 나옵니다.

### 위쪽 단추들

| 단추 | 하는 일 |
|---|---|
| 🗺️ 지도로 보기 | 할 일을 마인드맵처럼 펼쳐 봅니다 |
| 🔽 모두 펼치기 | 사람 카드 안의 칸을 한 번에 열고 닫습니다 |
| 끝난 일 보기 | 묵은 완료 항목까지 펼칩니다 |
| ✎ 팀 고치기 | 팀원을 넣고 빼고, 이름·직책을 고칩니다 |

### 「그 밖」 칸

팀에 없는 사람이 맡은 일, 담당자 없는 공용 일이 여기 모입니다.

# 4. 💳 마케팅 비용 — 돈이 어디로 나가나

## 무엇을 넣나

광고비·구독료·외주비 — **한 번만 적어두면** 됩니다.

| 적는 것 | 예 |
|---|---|
| 이름 | ChatGPT Plus |
| 금액 | 20 (달러로 적어도 됩니다) |
| 주기 | 1개월 · 3개월 · 1년 · 2년 · 1회성 |
| 신청일 / 만료일 | 2026-01-15 |
| 종류 | 광고 · 구독 · AI · 외주 … |
| 작성자 | 적은 사람 |

## 무엇이 나오나

- **한 달에 얼마** / **올해 얼마** 가 저절로 계산됩니다
  - 올해 금액은 **실제 결제일 기준**입니다. 1개월짜리를 12월에 신청했으면 올해는 1번만 셉니다
- **💱 환율** — 달러로 적으면 원화로 환산해서 보여줍니다
- **⏰ 결제 일주일 전 알림** — 홈 화면에 크게 뜹니다. 깜빡하고 결제되는 일이 없습니다

## 정리 기능

| 기능 | 하는 일 |
|---|---|
| **＋ 구분 추가** | 브랜드가 아닌 것(회사 공통·사무실 등)을 만듭니다. 왼쪽 브랜드 목록엔 안 생깁니다 |
| **📁 폴더 만들기** | 구분이 많아지면 폴더로 묶어 접어둡니다 |
| **종류로 모아 보기** | "AI 비용만" 처럼 종류별로 거릅니다 |

> 📁 폴더는 **보기 좋으라고** 있는 것입니다. 접어둬도 금액 계산에는 영향 없습니다.
> 폴더를 지워도 **안에 든 구분과 비용은 그대로** 남습니다.

# 6. 브랜드별 화면 — 브랜드 하나의 모든 것

왼쪽에서 브랜드를 고르면 **그 브랜드 전용 화면**이 열립니다. 탭이 여러 개 있습니다.

| 탭 | 무엇을 넣나 |
|---|---|
| ✅ **할 일** | 그 브랜드 관련 업무 |
| 🤖 **자동화 · 바로가기** | 돌고 있는 자동화 기록 + 자주 쓰는 사이트 링크 |
| 📁 **자료** | 파일. NAS에 올라가서 누구나 받을 수 있습니다 |
| 💳 **비용** | 그 브랜드에 나가는 돈 |
| 📣 **마케팅 접점** | 어떤 채널로 고객을 만나나 |
| 📜 **여정** | 브랜드 연혁 — 언제 뭘 했나 |
| 📋 **기획서** | 기획 문서 |
| ✍️ **블로그** | 블로그 발행 기록 |

## 🔗 바로가기 — 미리보기가 나옵니다

링크를 등록하면 **그 사이트 화면이 작게 보입니다.** 이름만 봐서는 뭔지 모르는 링크를 눈으로 구분할 수 있습니다.

> 미리보기가 빈 화면이면 그 사이트가 외부 표시를 막아둔 것입니다. 수정에서 「안 보기」로 바꾸세요.

# 7. 📘 온보딩 — 팀 소개 · 올해 목표

새로 온 사람이 **이것만 읽으면 팀을 아는** 자료입니다.

## 구조

**단(섹션) → 항목 → 하위** 세 층입니다.

```
📅 2026년 목표          ← 단
  └ 브랜드전략팀 (PM)    ← 항목
      ├ 소라님           ← 하위
      │   기존 브랜드 정리 — POUR솔루션 · POUR공법 → OBM 브랜드
      └ 경선님
          아파트스퀘어 — 정보 비대칭 풀기
```

## 적는 법

- **글자를 누르면 그 자리에서 고쳐집니다.** 따로 편집 화면으로 안 갑니다
- 하위에 **설명이 없으면 「칩」**(회색 이름표)으로 작게 표시됩니다
- 칩에 마우스를 올리면 **✏️** 가 나옵니다 → 누르면 설명을 적습니다
- 설명을 적으면 **줄 형태로 바뀝니다** (소라님처럼)
- **＋ 하위 넣기** 로 사람·항목을 더 넣습니다

# 9. 👥 사람 관리 (관리자)

오른쪽 위 **내 이름 → 사람 관리**

| 기능 | 하는 일 |
|---|---|
| **＋ 사람 추가** | 아이디·이름·비밀번호를 정해 계정을 만듭니다 |
| **🚫 사용 중지** | 퇴사자 처리. 그 자리에서 접속이 끊깁니다. **기록은 남습니다** |
| **🧹 남긴 자료** | 그 사람이 쓴 것을 골라서 정리합니다 |

> ⚠️ **퇴사자는 [지우기]보다 [사용 중지]를 권합니다.**
> 누가 무엇을 했는지 기록이 남아야 나중에 찾을 수 있습니다.

### [지우기]를 누르면

그 사람의 **맡은 할 일 · 그로스보드 · 팀원 카드 · 루틴**이 전부 휴지통으로 갑니다.
할 일 화면에서 **아주 사라집니다** — 「그 밖」으로 내려가지 않습니다.
30일 안에는 휴지통에서 되돌릴 수 있습니다. (단, **계정 자체는 되돌릴 수 없습니다**)

# 10. 💾 저장 · 되돌리기 — 꼭 알아야 할 것

## 저장은 자동입니다

적으면 **저절로 저장**됩니다. 오른쪽 위에 **✓ 저장됨** 이 뜨면 끝입니다.

| 표시 | 뜻 |
|---|---|
| ● 수정됨 | 적는 중. 잠시 뒤 자동 저장 |
| ◌ 저장 중… | 올리는 중 |
| ✓ 저장됨 | NAS에 들어갔습니다 |
| ⚠ 저장 실패 | 아래 빨간 띠를 확인하세요 |

## 여러 명이 같이 써도 안 지워집니다

두 사람이 동시에 다른 것을 적어도 **둘 다 남습니다.**
같은 것을 동시에 고치면 **상대가 쓴 것도 따로 보관**되고 화면에 알려줍니다.

## 🗑 휴지통 — 30일

지운 것은 바로 없어지지 않고 **휴지통에 30일** 있습니다.
**업무 → 🗑 휴지통** 에서 되돌립니다.

> 실수로 지워도 괜찮습니다. 겁내지 말고 쓰세요.

## ↩︎ 되돌리기 (Ctrl+Z)

방금 한 일은 오른쪽 위 **↩︎** 로 되돌립니다.
