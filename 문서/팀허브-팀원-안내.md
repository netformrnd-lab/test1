## 왜 이렇게 하나요

팀허브는 **컴퓨터마다 · 사람마다** 저장 위치를 한 번 고릅니다.
거기서 공유폴더(Z:)를 고르면 그 사람 자료만 따로 떨어져서,
브랜드 허브의 할 일과 영영 안 이어집니다.

말로만 알려 주면 꼭 한두 명이 빠집니다. 그래서 **누르면 먼저 안내 쪽이
열리도록** 했습니다. 고를 칸을 그림으로 짚어 주고, NAS 가 살아 있는지도
미리 확인해서 보여 줍니다.

## 브랜드 허브 쪽은 손댈 것 없습니다

[팀 허브] → 미디어마케팅팀 을 누르면 **저절로 이 안내 쪽을 거쳐** 열립니다.
적어 두셨던 자리는 한 번만 바뀌고, 옛 자리는 그대로 적어 둡니다
(되돌리시려면 `✎` → **자리** 에 `mediam_TeamHub.html#/board` 라고 다시
적으시면 됩니다).

## 이미 Z: 로 쓰고 계셨다면

자료를 먼저 NAS 로 옮기고 연결하세요 (순서가 중요합니다).

1. File Station → `넷폼알앤디 공유폴더 / 00. 미디어마케팅팀 /
   미디어마케팅팀 브랜드허브 / DB_미디어마케팅팀 브랜드허브`
2. **안에 든 것 전부** 선택 → **복사** (이동 말고 복사)
3. `web / brand / DB_teamhub / 미디어마케팅팀` 에 붙여넣기
4. 그다음 위 링크로 들어가 **[연결]**
