# 브랜드기준 폴더 — 이게 뭐예요?

이 폴더는 **우리 팀의 "정답지"** 입니다.

AI가 블로그든 카페 글이든 보도자료든 쓸 때, **항상 이 폴더를 먼저 읽고** 씁니다.
그래서 여기만 잘 채워두면:

- 담당자가 3명이어도 **같은 목소리**로 글이 나옵니다
- 사람이 바뀌어도 **같은 메시지**가 반복됩니다
- 매번 "우리 브랜드는 이런 톤이고…" 하고 설명할 필요가 없습니다

## ⚠️ 지금 꼭 확인해야 할 것 2가지

### 1) 수치·실적이 아직 2025년 기준입니다
`01-브랜드-원메시지.md` 의 실적 표(K-APT 1위, 260만 세대, 700건, 850억 등)는
기존 생성기에 적혀 있던 값을 그대로 옮긴 것입니다.
**2026년 기준으로 맞는지 확인하고 `검증일` 칸을 채워주세요.**
확인 전까지 AI는 이 값을 그대로 씁니다.

### 2) 이 표에 없는 수치는 아예 못 씁니다
AI는 표에 없는 수치·인증·수상·순위를 만나면 `[확인 필요: 항목명]` 으로 **비워둡니다.**
지어내지 않습니다. 이게 원칙입니다.

## 채울 때 지켜야 할 것 딱 하나

**추상적인 말 대신 실제 문장을 적으세요.**

| ❌ 이렇게 쓰지 마세요 | ✅ 이렇게 쓰세요 |
|---|---|
| 톤: 전문적이고 신뢰감 있게 | 한 문장 15~20자. 2~3문장마다 줄 바꿈. "혁신" 금지 |
| 고객: 50대 관리소장 | "전문감리기관에 맡기면 책임이 분산됩니다" 가 먹히는 사람 |
| 금지: 과장 표현 | `보장` → `확보` / `안전 관리` → `품질 검토` |

AI는 추상적인 지시는 못 알아듣고, **예시 문장은 정확히 따라 합니다.**
