## 아파트스퀘어 앱 — 콘텐츠에서 반드시 다룰 것

앱은 단순한 공유 도구가 아니라, **전문 감리 프로세스가 고객에게 전달되는 방식**입니다.

고객이 앱에서 직접 확인할 수 있는 것:
1. **공사 일정·진행 현황** — 오늘 어떤 공정, 다음은 언제, 전체 공정률 %
2. **감리일지** (건축법 시행규칙 별지 제21호서식) — 감리일지 전문, 자재성능 서류 확인 결과, 마감상태 육안 확인, 균열보수 바탕면 확인, 특이사항·지적사항·처리결과
3. **현장 사진** — 공정별 시공 전·중·후, 지적사항 발생 시, 시정 완료 후
4. **자재 검수 기록** — 투입 자재 승인 서류, 설계도서 대비 실제 투입 자재
5. **지적사항 및 처리 현황** — 발견된 문제와 시공사 요청, 처리 완료 여부

**글에서 앱을 표현하는 방식 (이 문장들을 그대로 쓰세요)**
- "앱을 열면 오늘 현장에서 무슨 일이 있었는지 바로 확인할 수 있습니다."
- "감리일지가 앱에 실시간으로 올라옵니다. 기다리지 않아도 됩니다."
- "현장에 가지 않아도 됩니다. 앱이 현장을 대신 보여드립니다."
- "말로 '잘 하고 있습니다'가 아니라, 앱에 기록으로 남습니다."
- "공사가 끝난 후에도 앱에 모든 기록이 남아 있습니다."

> **앱 섹션은 글의 중간과 마무리에 반드시 등장합니다. 앱 화면 이미지 자리도 반드시 포함합니다.**

### 감리일지 실제 점검 항목 (글에서 구체적으로 활용 가능)

**외벽 도장 공사**
- 자재성능 관련 서류 확인 / 마감상태 육안 확인 / 균열보수 바탕면 확인
- 도막할 곳 주변 보양 확인 (오염·손상 방지) / 도장 시 발생한 도막의 결함 확인

**지하주차장 공사**
- 자재성능 관련 서류 확인 / 마감상태 육안 확인 / 방수재 반입 및 적정사용량 확인
- 공사 범위 및 시공 구간 확인 / 작업 구간 주변 보양 조치 확인 / 바탕면 건조 상태 확인
- 자재 적재 위치 및 MSDS 확인 / 작업 전 안전교육 실시 확인

**실제 지적사항 예시 (감리일지에 기록되는 내용)**
- "균열 보수 누락 부분 확인 → 시공사에 추가 보수 요청"
- "새벽서리로 인해 공정 진행 중지"
- "세대 오염 입주민 의견 취합 후 일괄처리"
- "우천으로 외부 공정 일시 중지"
- "에폭시 도장 완료됐으나 미비점 다수 → 정리 중"
- "동표시 색상 변경 요청 접수 → 시공사 협의 후 진행"
