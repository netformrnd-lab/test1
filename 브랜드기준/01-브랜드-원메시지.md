# 브랜드 원메시지

> **원메시지 = 이 브랜드가 고객에게 하는 딱 한 문장.**
> 모든 블로그·SNS·랜딩·제안서는 결국 이 한 문장을 다르게 말한 것이어야 합니다.
> 사람이 바뀌어도 이 문장은 안 바뀝니다.

작성 규칙
- 브랜드마다 하나씩 블록을 복사해서 씁니다.
- 원메시지는 **한 문장, 40자 이내**. 두 문장이 되면 아직 안 좁혀진 겁니다.
- 서브메시지는 **3개까지**. 원메시지를 뒷받침하는 근거입니다.
- "증거"에는 **확인 가능한 사실만** 적습니다. 여기 없는 주장은 콘텐츠에 못 씁니다.

> ( 여기를 채워주세요 — 40자 이내 한 문장 )

**서브메시지 3개**

**증거 (확인 가능한 사실만)**

- 수상·선정: ( 없으면 "없음" )
- 실적 수치: ( 예: 누적 시공 OO건 — 반드시 출처 있는 것만 )
- 고객 사례: ( 공개 가능한 사례명 )

**이 브랜드가 절대 안 하는 말**

( 고객이 우리를 고를 이유. "품질이 좋다" 말고 구체적으로 )
