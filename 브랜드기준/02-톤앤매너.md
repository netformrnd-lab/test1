# 톤앤매너 · 문장 규칙

> AI가 글을 쓸 때 **문장 단위로 따라 하는 규칙**입니다.
> 출처: 팀이 쓰던 생성기 3종의 브랜드 보이스 원칙·후처리 치환 규칙을 옮긴 것입니다.

---

# 1. 공통 문장 스타일 — 네이버 블로그·카페용

우리 채널 글은 **모바일에서 읽힙니다.** 그래서 문장을 극도로 짧게 끊습니다.

### 규칙
1. **한 문장 = 최대 한 줄 (15~20자 이내)**
2. **2~3문장마다 반드시 단락 구분** (`<br><br>`)
3. **각 단락은 3~4줄 이내**
4. 독자에게 직접 말 걸듯 씁니다

### 나쁜 예 / 좋은 예

❌ 나쁜 예
```
기존 방식은 A/B 두 가지를 직접 섞어서 사용하는 방식으로, 비율이 맞지 않으면 굳지 않거나 강도가 떨어지는 문제가 발생합니다.
```

✅ 좋은 예
```
기존 방식은 A/B 두 가지를
직접 섞어서 사용합니다.

비율이 조금만 달라져도
굳지 않거나, 강도가 떨어집니다.
```

### 자주 쓰는 말 걸기 문장
- "혹시 이런 경험 있으신가요?"
- "왜 이런 일이 반복될까요?"
- "이유는 단순합니다."
- "바로 이 부분이 핵심입니다."

# 4. 아파트스퀘어 — 고객 경험 중심 서술법

아파트스퀘어는 **고객경험 중심 브랜드**입니다.
독자가 읽으면서 **"아, 이 회사랑 함께하면 이런 경험을 하겠구나"** 라고 느껴야 합니다.

### 정보 나열 ❌ → 경험 장면 ✅

❌ 나쁜 예 (정보 나열)
```
저희는 감리보고서를 앱으로 공유합니다. ✔️ 오늘 어떤 공정이 진행됐는지...
```

✅ 좋은 예 (경험 장면)
```
공사 3일차 아침, 앱에 알림이 왔습니다.
"오늘 3동 균열보수 작업 완료, 사진 첨부."

현장에 가지 않았는데
뭐가 됐는지 바로 알 수 있었습니다.
```

### 경험 장면 예시
- "공사 시작 전에 저희가 먼저 연락드립니다. '이번 공사 일정과 담당자 연락처 공유드립니다.'"
- "현장에서 점검 필요 항목이 발견되면 바로 공유드립니다. 기다리지 않으셔도 됩니다."
- "공사가 끝나고 나서도 궁금한 점이 생기면 언제든지 연락 주세요. 저희가 확인해드립니다."

### 친절한 말투 예시
- "걱정 마세요, 저희가 챙기고 있습니다."
- "혼자 고민하지 마시고 편하게 말씀해 주세요."
- "저희가 옆에 있겠습니다. 😊"
- "공사 중에 뭔가 이상하다 싶으시면 바로 연락 주세요."

### CTA 직전 마무리 문장 패턴
> "비슷한 상황이신 분들, 혼자 고민하지 마시고 댓글이나 연락처로 편하게 말씀해 주세요.
> 저희가 함께 방법을 찾아드리겠습니다."

⚠️ 억지로 **"파트너"** 라는 단어를 쓰지 말고, **구체적인 경험 장면**으로 보여주세요.
