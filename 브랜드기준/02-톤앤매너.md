# 톤앤매너 · 문장 규칙

> AI가 글을 쓸 때 **문장 단위로 따라 하는 규칙**입니다.
> "전문적으로" 같은 추상적인 말 대신, **예시 문장**을 넣어주세요.
> AI는 예시를 정확히 따라 합니다.

---

## 1. 기본 말투

- 문체: ( 예: `~합니다` 존댓말 / `~한다` 평서체 — 채널별로 다르면 아래 3번에 )
- 1인칭: ( 예: "저희" / "넷폼알앤디는" — 하나로 통일 )
- 고객 호칭: ( 예: "고객님" / "담당자분" )
- 한 문장 길이: ( 예: 40자 이내, 쉼표 2개 이상이면 자른다 )
- 한 문단 길이: ( 예: 3문장 이내 )

**좋은 문장 예시 3개** ← 여기가 제일 중요합니다
1. ( 우리 브랜드다운 실제 문장을 그대로 붙여넣으세요 )
2. ( 여기를 채워주세요 )
3. ( 여기를 채워주세요 )

**나쁜 문장 예시 3개** (왜 나쁜지도 적어주세요)
1. ( 예: "혁신적인 솔루션으로 고객 만족을 실현합니다" → 아무 말도 안 한 문장 )
2. ( 여기를 채워주세요 )
3. ( 여기를 채워주세요 )

---

## 2. 금지어 · 주의어

**절대 쓰지 않는 말**
- 최고, 업계 1위, 국내 유일, 완벽한, 100% — ( 근거 문서가 있으면 예외, 그때는 출처 표기 )
- ( 여기에 추가해주세요 )

**조심해서 쓰는 말**
| 쓰지 말 것 | 대신 이렇게 |
|---|---|
| 저렴한 | 예산에 맞춘 |
| 무조건 | 대부분의 경우 |
| ( 추가 ) | ( 추가 ) |

**AI가 자주 쓰는데 우리는 안 쓰는 말** (발견하는 대로 계속 추가)
- "~에 대해 알아보겠습니다"
- "결론적으로", "종합적으로 볼 때"
- 이모지 남발
- ( 여기에 추가해주세요 )

## 4. 표기 규칙

- 회사명 정식 표기: ( 예: 넷폼알앤디 / (주)넷폼알앤디 — 어느 쪽을 쓸지 )
- 영문 표기: ( 여기를 채워주세요 )
- 브랜드명 표기: ( 예: 항상 한글 / 영문 병기 )
- 숫자: ( 예: 1,000 처럼 세 자리 콤마 )
- 단위: ( 예: 3㎡ 붙여쓰기 / 3 ㎡ 띄어쓰기 )
- 날짜: ( 예: 2026년 3월 12일 / 2026.03.12 )
- 전문용어: ( 예: 처음 나올 때 한 번은 괄호로 풀어쓴다 )
