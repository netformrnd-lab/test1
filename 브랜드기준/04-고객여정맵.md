# 고객 여정 맵 (퍼널)

> **인지 → 관심 → 비교 → 문의 → 계약 → 이용 → 재구매 → 추천**
> 8단계마다 "고객이 뭘 고민하는지 / 뭘 봐야 하는지 / 어디서 만나는지 / 뭐라고 말할지"를 정합니다.
>
> 새로 만들 때는 `/cm-journey` 를 쓰세요.
>
> ⚠️ 이 표가 채워지면, 콘텐츠를 만들 때 **"이 콘텐츠는 어느 칸을 채우는 건가?"** 로 판단할 수 있습니다.
> 비어 있는 칸이 바로 고객이 이탈하는 지점입니다. — 2026년 우리 팀 1순위 과제.
