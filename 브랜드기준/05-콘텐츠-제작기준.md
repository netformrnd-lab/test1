# 콘텐츠 제작 기준 · 발행 전 검수 체크리스트

> **이 체크리스트를 통과하지 못한 콘텐츠는 발행하지 않습니다.**
> `/cm-review` 를 돌리면 AI가 이 항목대로 하나씩 검사해서 표로 알려줍니다.
> 단, **최종 발행 결정은 사람이 합니다.** AI는 반려 사유까지만 알려줍니다.

---

## A. 무조건 통과해야 하는 것 (하나라도 걸리면 발행 금지)

| # | 항목 | 확인 방법 |
|---|---|---|
| A1 | **사실 오류가 없다** | 수치·날짜·인증명·제품명이 원문과 일치하는가 |
| A2 | **근거 없는 최상급 표현이 없다** | "최고·1위·유일·100%" → `01-브랜드-원메시지.md` 의 증거 항목에 있는가 |
| A3 | **확정되지 않은 가격을 말하지 않는다** | 가격·할인율은 승인된 자료에만 |
| A4 | **경쟁사를 직접 비방하지 않는다** | 비교는 사실 기준으로만, 브랜드명 직접 거론 시 팀장 확인 |
| A5 | **고객 정보·사진에 동의를 받았다** | 사례·후기·현장 사진 사용 동의 여부 |
| A6 | **저작권 문제가 없다** | 이미지·인용문 출처 확인 |

## B. 브랜드 기준 (걸리면 수정 후 재검수)

| # | 항목 | 확인 방법 |
|---|---|---|
| B1 | **원메시지에서 벗어나지 않았다** | `01-브랜드-원메시지.md` 의 한 문장으로 이 콘텐츠를 요약할 수 있는가 |
| B2 | **톤앤매너를 지켰다** | `02-톤앤매너.md` 의 금지어·문장 길이·문체 |
| B3 | **정해진 페르소나에게 말하고 있다** | `03-페르소나.md` 의 누구를 향한 글인지 명확한가 |
| B4 | **고객 여정 단계가 명확하다** | `04-고객여정맵.md` 의 어느 단계용인지 한 칸으로 지목 가능한가 |
| B5 | **표기 규칙을 지켰다** | 회사명·브랜드명·숫자·단위·날짜 |

## C. 콘텐츠 품질 (걸리면 수정 권고)

| # | 항목 | 확인 방법 |
|---|---|---|
| C1 | **첫 문단에서 답을 준다** | 검색으로 들어온 사람이 3초 안에 "여기 답이 있네" 하는가 |
| C2 | **CTA가 하나다** | 행동 유도가 두 개 이상이면 하나로 줄인다 |

| C4 | **AI가 쓴 티가 나는 문장이 없다** | `02-톤앤매너.md` 의 "AI가 자주 쓰는데 우리는 안 쓰는 말" |
| C5 | **검색 키워드가 자연스럽게 들어갔다** | 억지로 반복하지 않았는가 |
| C6 | **다음 행동으로 이어지는 링크가 있다** | 여정상 다음 단계 콘텐츠로 연결 |

## 발행 프로세스 (2026년 우리 팀이 세울 업무 체계)

```
1. 기획      담당자가 여정 단계 + 페르소나 + 키워드를 정한다
2. 초안      /cm-blog, /cm-sns, /cm-press 등으로 초안 생성
3. 자가검수   /cm-review 실행 → A·B·C 표에서 걸린 것 수정
4. 팀 검수   다른 담당자 1명이 읽는다 (A 항목만이라도)
5. 발행      담당자가 채널에 올린다
6. 기록      콘텐츠/ 폴더에 최종본 저장 + 캘린더에 발행일 기록
7. 성과      2주 후 /cm-keyword 또는 성과 확인, 07-VOC.md 에 반응 기록
```

**절대 건너뛰지 않는 단계: 3번(자가검수)과 5번 직전의 사람 확인.**
