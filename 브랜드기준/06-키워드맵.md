# 키워드 맵 (SEO / GEO / AEO)

> 우리가 검색에서 먹으려는 키워드 목록입니다.
> 새 주제를 잡을 때는 `/cm-keyword` 를 먼저 돌리고, 결과를 여기에 옮겨 적으세요.

**용어 정리**
- **SEO** — 네이버·구글 검색 결과 상위 노출
- **GEO** — AI(ChatGPT·Perplexity 등)가 답변할 때 우리 글을 인용하게 만들기
- **AEO** — "OO는 무엇인가요?" 같은 질문형 검색에 직접 답이 되게 만들기
