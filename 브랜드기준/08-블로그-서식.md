# 1. POUR공법 블로그

## 1-1. 글 구조 (이 순서를 지킵니다)

```
1  독자 공감 인용구 2개 (각각 별도 박스)
2  "혹시 이런 걱정으로 이 글을 클릭하셨나요?" 공감 응답
3  전환 문구: "그렇다면 지금부터 알려드릴 내용이 꼭 필요한 해결책이 될 겁니다."
4  사진 자리 박스 (현장 사진)
5  문제 상황 설명 — 현장에서 실제 겪는 일
6  "왜 이 문제가 반복될까요?" 원인 분석
7  기존 방식의 한계 (① ② ③ 로 구체적으로)
8  사진 자리 박스
9  POUR공법 해결책 소개 (제품명 + 핵심 특징)
10 🔥 핵심 특징 3가지 (각각 별도 섹션, 사진 자리 포함)
11 사진 자리 박스 (시공 완료)
12 마무리 문구 (짧고 강하게)
13 CTA 박스
14 웹사이트 링크 박스
15 해시태그
```

**분량**: 전체 3,000자 이상 / 본문 섹션 6개 이상 / 각 섹션 4~6문장 / 사진 자리 5개 이상

# 2. POUR공법 뉴스·소식

## 2-1. 글 구조

```
1  인사말 + 소식 예고 — "안녕하세요. POUR공법입니다:)"
2  핵심 소식 1줄 요약
3  사진 자리 박스 (행사/제품/현장)
4  소식의 배경 — 왜 중요한가
5  핵심 내용 상세 (수치·데이터 포함, 1️⃣2️⃣3️⃣ 활용)
6  사진 자리 박스
7  POUR공법의 의미·가치 — 독자에게 어떤 혜택인지
8  관련 실적·인증 데이터 (✅ 활용)
9  마무리 (앞으로의 방향 + 감사 인사)
10 CTA 박스
11 웹사이트 링크 박스
12 해시태그
```

## 2-2. 도입부 문체 (그대로 따라 쓰기)

```
POUR공법입니다:)
```

# 3. 아파트스퀘어 블로그

## 3-1. 문체 특징

- 짧은 문장, **넓은 여백**, 줄 바꿈 많이
- **현장에서 직접 본 장면이나 경험으로 시작**
- 독자 감정을 건드리는 표현 ("참 마음이 안타까웠습니다")
- 질문을 던지면서 독자를 끌어당기기
- "오늘은 그 방법을 알려드리겠습니다" 식의 후킹
- 전문가지만 딱딱하지 않게, 솔직하게
- **문단이 가운데 정렬**입니다 (POUR과 다른 점)

## 3-2. 도입부 (이 리듬 그대로)

```html
<div style="text-align:center;margin:32px auto 24px;max-width:480px;">
  <div style="font-size:24px;color:#cccccc;line-height:1;margin-bottom:8px;">&ldquo;</div>
  <p style="font-size:16px;color:#333;font-weight:500;line-height:2;font-family:'Noto Serif KR',serif;">[독자가 실제로 한 말]<br>[2~3줄로 끊어서]</p>
  <div style="font-size:24px;color:#cccccc;line-height:1;margin-top:8px;text-align:right;">&rdquo;</div>
</div>

<p style="text-align:center;font-size:14px;color:#555;line-height:2;margin:12px 0 20px;">안녕하세요. 아파트스퀘어 건축사 조현식입니다.</p>

<p style="text-align:center;font-size:14px;color:#555;line-height:2;margin:12px 0 20px;">[현장에서 본 장면]<br>[짧게 끊어서]</p>

<p style="text-align:center;font-size:14px;color:#555;line-height:2;margin:12px 0 20px;">참 마음이 안타까웠습니다.<br>왜 이런 일이 생기는 걸까요?</p>

<p style="text-align:center;font-size:15px;color:#004e82;font-weight:700;line-height:2;margin:8px 0;">오늘은 그 방법을 알려드리겠습니다.</p>
```

# 4. 전아모 카페 글 (아파트스퀘어)

> 대상: 전아모(전국아파트입주자대표회의모임) 등 아파트 관련 네이버 카페

## 4-1. 문체

- 전문가지만 **가볍고 친근하게.** 카페 커뮤니티 멤버처럼 자연스럽게
- 무겁지 않게, 딱딱하지 않게
- **"저는", "저희는" 1인칭** 사용
- 현장 이야기를 가볍게 공유하는 느낌
- 독자와 같은 눈높이
- 이모지 적절히 (너무 많으면 ❌)
- 시작은 **"안녕하세요. 아파트스퀘어 건축사 조현식입니다."**

## 4-2. 글 유형별 구조

| 유형 | 구조 |
|---|---|
| **시공 과정 설명** | 도입(공감) → 왜 중요한지 → 단계별 시공 과정(이미지 자리) → 아파트스퀘어 감리 소개 → 연락처 |
| **판단 기준 제시** | 상황 공감 → 판단 기준 → 공사 우선순위 → 무상 현장 진단 소개 → 연락처 |
| **투명성 증명** | 공사 불투명성 공감 → 감리 방식 → 앱으로 직접 확인 가능 → 연락처 |
| **단지 사례** | 단지 상황 → 문제 상황 → 진단 과정 → 공사 진행 → 결과 → 아파트스퀘어 소개 |
| **브랜드 소개** | 고객 고민 공감 → 서비스 구조 → 고객 여정 → 연락처 |
| **참여 유도** | 독자가 자기 상황을 **댓글로 공유하게** 유도 (전아모에서 참여율 높음) |

## 4-3. 마무리 패턴

> "비슷한 상황이신 분들, 혼자 고민하지 마시고 댓글이나 연락처로 편하게 말씀해 주세요.
> 저희가 함께 방법을 찾아드리겠습니다."

## 4-4. 이미지 자리 표기 (카페는 HTML 대신 텍스트)

