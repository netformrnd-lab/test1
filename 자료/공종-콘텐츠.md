# 공종별 콘텐츠 소스

제안서 25건에서 뽑아 정리한 자료입니다. 특정 업체나 공법명은 모두 지웠습니다.
공법을 파는 내용이 아니라, **단지가 무엇을 확인해야 하는지**로 뒤집어 정리했습니다.

## 외벽 — 균열보수 · 재도장

콘크리트는 온도에 따라 수축·팽창하므로 균열을 완전히 막을 수 없습니다. 문제는 균열 자체가 아니라 그 틈으로 빗물이 들어간 다음입니다. 중성화가 진행되고 철근이 부식되기 시작하면 도장 문제가 아니라 구조 문제가 됩니다.

### 하자 유형

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 도장면 들뜸·박리 | 반복적인 수축팽창, 도막 접착력 저하 | 바탕면 손상, 재도장 주기 단축 |
| 층간 조인트 대균열 | 타설 끊어치기 부위·접합부 | 누수, 중성화, 철근 부식 |
| 균열 내 빗물 침투 | 미보수 균열의 모세관 흡수 | 철근 부식, 녹물, 콘크리트 박리 |
| 곡각지점·모서리 균열 | 퍼티·몰탈로는 거동 대응 불가 | 재균열, 콘크리트 탈락 |
| 창호 주변 사인장 균열 | 모서리 보강철근 배근 미흡, 실리콘 노후 | 누수, 결로, 곰팡이 |
| 열화·중성화 박락 | 화학적·물리적 요인에 의한 기능 저하 | 낙하 위험, 녹물 노출 |

### 단지가 확인할 것

- 고압세척과 바인더(하도) 작업이 견적에 있나. 바탕정리를 빼면 몇 년 안에 다시 들뜹니다. 견적을 낮추려 가장 먼저 빠지는 항목입니다.
- 쵸킹 여부를 진단서에 적었나. 손으로 문질렀을 때 흰 가루가 묻어나면 바인더 작업이 필수입니다.
- 균열을 폭·깊이·거동 여부로 나눠 보수 방법을 다르게 잡았나, 아니면 전부 같은 방법인가.
- 창호 주변과 곡각지점을 별도 항목으로 잡았나. 여기가 재균열이 가장 잦은 곳입니다.
- 도장 횟수와 도막 두께가 시방서에 숫자로 있나. “2회 도장”만으로는 검측 기준이 되지 않습니다.

## 옥상 — 슬라브 방수

옥상 방수층을 깨뜨리는 주범은 비가 아니라 자외선과 계절 온도차입니다. 방수층이 수축과 팽창을 반복하며 갈라지고, 그 틈으로 물이 들어갑니다. 그리고 누수는 넓은 바닥 한가운데가 아니라 가장자리와 이음부에서 시작됩니다.

### 하자 유형

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 방수층·슬라브 균열 | 외기 영향, 콘크리트 수축팽창 | 건물 누수 → 세대 누수 |
| 드레인 주변 누수 | 배관 관통부 틈새, 구배 불량 | 물고임, 중성화, 결로·곰팡이·악취 |
| 콘크리트 중성화 | 관통 누수의 반복 | 균열 확대의 악순환 |
| 모서리·곡각지점 누수 | 균일한 방수층 형성이 어려움 | 가장 잦은 재발 지점 |
| 기타 구조물 이음부 | 거동이 잦아 실리콘·퍼티로 부족 | 벌어짐 → 재누수 |
| 파라펫·두겁 상단 균열 | ‘ㄷ’자 상단부 노출, 벽체 균열 | 백화, 콘크리트 탈락·낙하 |

### 공법 계열의 일반적 특성

| 계열 | 일반적 장점 | 일반적 한계 |
|---|---|---|
| 도막계 | 이음매 없이 형성, 복잡한 형상 대응 | 도막 두께 관리가 품질을 좌우, 곡각부 균일 도포가 어려움 |
| 시트계 | 공장 생산이라 두께가 균일 | 접합부와 마감부가 취약부, 복잡한 옥상은 시공이 까다로움 |
| 복합·보강 | 취약부만 별도로 보강 가능 | 공정이 늘어 검측 지점이 늘어남 |

### 단지가 확인할 것

- 드레인 주변, 파라펫 두겁, 곡각지점, 이음부가 별도 항목으로 잡혀 있나. 실제 누수는 여기서 시작하는데 면적 단가로만 잡으면 이 부분이 사라집니다.
- 구배(물매) 개선이 포함돼 있나. 물고임을 그대로 두고 방수만 새로 하면 같은 자리에서 재발합니다.
- 바탕면 함수율과 균열 조사 결과가 착공 전에 문서로 있나.
- 도막이면 두께, 시트면 접합 폭이 숫자로 정해져 있나. 숫자가 없으면 검측할 수 없습니다.
- 하자보증의 범위 — 방수층만인지, 취약부 보강까지인지. 기간보다 범위가 중요합니다.

## 지붕 — 아스팔트 슁글 · 금속지붕 / 칼라강판

아스팔트 슁글은 원래 저층 목조주택용 자재입니다. 국내 고층 아파트에 적용되면서 강풍과 온도차에 의한 탈락·낙하 문제가 나타났습니다. 금속지붕과 칼라강판은 가볍고 내구성이 좋지만 열에 따른 신축이 크고, 표면 부식이 진행되면 맞물림이 풀립니다. 공용부 마감재가 떨어져 2차 피해가 생기면 관리 주체 책임 문제로 이어집니다.

### 하자 유형

| 구분 | 현상 | 원인 |
|---|---|---|
| 슁글 | 탈락·낙하, 누수 | 강풍·태풍에 의한 고정 상태 파손 |
| 슁글 | 후레싱 탈락 | 고정부 품질 저하, 이음부 균열 |
| 슁글 | 배수로·대피소 누수 | 트렌치·대피소 균열, 바탕면 손상 |
| 공통 | 수직-수평면 이음부 침투 | 실리콘 마감부가 수축팽창으로 벌어짐 |
| 금속 | 표면 부식·변질 | 노후로 누수층 소멸 |
| 금속 | 기와·강판 단차 벌어짐 | 열에 의한 신축, 맞물림 풀림 |
| 금속 | 서까래 기능 저하 | 지지 구조 노후 |

### 단지가 확인할 것

- 고정 상태 점검을 어떤 방법으로 했나. 아래에서 올려다본 육안 확인만으로는 들뜸과 풀림을 잡지 못합니다.
- 후레싱, 배수로, 대피소를 별도로 봤나. 면적 위주 견적에서 빠지기 쉬운 지점입니다.
- 부분 보수로 될 상태인지 교체가 필요한 상태인지, 판단 근거가 문서에 있나.
- 낙하 위험 구간을 표시하고 통행 동선과 분리했나.
- 작업 중 낙하물 방지 계획과 안전 조치가 견적에 반영됐나.

## 지하주차장 — 바닥 도장 · 천장 누수

바닥 에폭시는 굳으면 단단하지만 습기를 통과시키지 못합니다. 지하는 습기가 필연적이라, 바탕면 수분이 빠져나가지 못하면 들뜸과 기포가 생깁니다. 천장 누수는 성격이 다릅니다. 대부분 지상에서 내려옵니다 — 화단·놀이터·배수로 아래 비노출 방수층이 깨져 물이 관통합니다.

### 하자 유형 · 바닥

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 바닥 균열 | 바탕 콘크리트 균열이 그대로 전이 | 도장면 갈라짐, 재시공 |
| 중성화·강도 저하 | 노출 콘크리트 열화, 차량 충격 | 깨짐, 탈락 |
| 들뜸·부풀음 | 바탕면 습기가 빠져나가지 못함 | 면 단위 박리, 전면 재시공 |
| 코너 슬립·소음·마모 | 차량 진입 시 마찰 집중 | 미끄럼 사고, 민원 |

### 하자 유형 · 천장과 벽체

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 천장 누수 | 지상 화단·놀이터·배수로 아래 비노출 방수층 파손 | 지하에서만 보면 원인을 못 찾음 |
| 기둥 이음부·모서리 누수 | 구조체 이음부의 거동 | 철근 부식 |
| 배관·배선 주변 누수 | 설비 이음부 문제 (콘크리트 문제 아님) | 엉뚱한 곳을 보수하게 됨 |
| 골재 몰림·재료분리 | 타설 시 기둥 내 틈새 발생 | 콘크리트 박락, 누수 |
| 천장 슬라브 균열 | 차량 통행 진동, 수축팽창 | 균열 확대, 누수 |

### 단지가 확인할 것

- 바닥 재시공 전에 바탕면 함수율을 측정했나. 들뜸 하자의 상당 부분이 이것 하나로 설명됩니다.
- 습기 대응 방법이 견적에 있나, 아니면 기존 위에 그대로 덧칠하는 구성인가.
- 천장 누수의 발생 지점을 지상 어느 구역에서 오는지 추적했나. 지하에서만 보면 같은 자리를 반복 보수하게 됩니다.
- 콘크리트 문제인지 설비 배관 문제인지 구분했나. 원인이 다르면 공사 주체도 비용 부담도 달라집니다.
- 주차 통제 계획과 양생 기간이 일정에 반영됐나. 이 두 가지가 입주민 민원의 대부분입니다.

## 단지 내 도로 · 보도 — 아스콘 포장 · 보도블럭 / 경계석

아스콘은 유제의 접착력이 떨어지며 균열이 생기고, 그 틈으로 물이 들어간 상태에서 반복 하중을 받으면 포트홀로 커집니다. 보도블럭과 경계석은 하부 지반이 고르지 않거나 고정이 부실하면 침하와 이탈로 이어집니다. 둘 다 미관 문제가 아니라 보행자와 차량 안전 문제로 직결됩니다.

### 하자 유형 · 아스콘 포장

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 맨홀 주변 균열 | 단단한 맨홀과 강도가 낮은 주변 아스콘의 경계에 충격 집중 | 거북등 균열, 패임, 잡초 |
| 세로·가로·거북등 균열 | 접착력 저하, 온도 변화, 집중 하중 | 균열이 이어지며 면 단위로 확대 |
| 포트홀 | 균열 방치 + 수분 침투 + 반복 하중 | 차량 손상, 배상 문제 |
| 밀림·들뜸 | 층간 접착력 부족 | 같은 자리에서 하자 반복 |
| 미끄럼 저항 부족 | 노후 골재, 표면 오염물 | 우천·결빙 시 경사로 사고 |

### 하자 유형 · 보도블럭과 경계석

| 현상 | 원인 | 방치하면 |
|---|---|---|
| 경계석 이탈·돌출 | 고정 부실 | 틈새 이물질 → 배수 불량 → 보행자 사고, 침수 |
| 보도블럭 파손·침하 | 하부 지반 불균일, 반복 하중, 수분 침투 | 단차 발생, 보행 걸림 |
| 들뜸 | 모래층 유실 | 밟을 때 흔들림, 재시공 |

### 단지가 확인할 것

- 표면만 덧씌우는 구성인지, 기층까지 보는 구성인지. 기층이 약한데 표면만 새로 깔면 같은 자리에서 다시 꺼집니다.
- 맨홀과 배수구 주변을 별도 항목으로 잡았나. 균열이 가장 먼저 생기는 곳인데 면적 단가에 묻히기 쉽습니다.
- 보도블럭은 하부 지반 다짐이 견적에 있나. 블록만 다시 깔면 재침하합니다.
- 경사로와 출입구의 미끄럼 저항을 따로 봤나. 사고가 나는 지점은 정해져 있습니다.
- 공사 중 차량 동선과 보행 동선 확보 계획이 있나. 단지 내 도로는 통행 차단이 곧 민원입니다.

## 영상 주제 후보

- 외벽 재도장, 지금 해야 하나
- 외벽에 묻어나는 흰 가루의 정체
- 재도장 견적에서 바탕정리가 빠지면
- 균열은 다 같은 균열이 아닙니다
- 외벽 녹물, 도장으로 덮으면 안 되는 이유
- 옥상 방수, 비 때문이 아닙니다
- 옥상 누수는 여기서 시작됩니다
- 물고임을 두고 방수만 다시 하면
- 도막이냐 시트냐, 무엇으로 갈리나
- 방수 하자보증, 어디까지 되나
- 지붕 슁글이 떨어지는 진짜 이유
- 우리 아파트 지붕, 보수인가 교체인가
- 지붕 마감재 탈락, 누가 책임지나
- 옥상에서 놓치기 쉬운 후레싱
- 지하주차장 바닥이 들뜨는 이유
- 천장 누수인데 지상을 봐야 하는 이유
- 에폭시 위에 다시 칠하면 되나
- 누수 원인이 콘크리트가 아닐 때
- 주차 통제, 며칠이면 끝나나
- 포트홀은 왜 같은 자리에 다시 생기나
- 맨홀 주변이 먼저 깨지는 이유
- 보도블럭만 다시 깔면 안 되는 이유
- 덧씌우기냐 걷어내기냐
- 단지 도로 공사, 며칠 통제되나
