# 헤이젠으로 영상 만들며 알아낸 것

여러 번 만들어 보고 고치면서 확인한 내용입니다.
다시 만들 때 이걸 모르면 같은 실패를 반복하게 됩니다.

## 장면 (가장 중요)

- 헤이젠 Video Agent는 **"컷"이 아니라 "장면(Scene)" 단위**로 만듭니다.
- **"장면을 N개 만들어라"는 지시를 듣지 않습니다.** 길이와 무관하게 자기가 정합니다.
- 대신 **장면을 하나씩 번호 매겨 나열하면 그대로 만듭니다.**
  `장면 1 [0~13초] …` 처럼 구간·화면·내용을 각각 적어 주는 방식입니다.
- 챕터를 7개 주면 장면도 7개가 나옵니다. 챕터 수 = 장면 수라고 보면 됩니다.
- **장면 하나는 13초 안팎**이 적당했습니다.
  이보다 길면 한 화면에 오래 머물러 지루하고, 훨씬 짧으면 빨리 감기처럼 정신없어집니다.
  (29개까지 쪼개 봤더니 영상이 너무 분주해졌습니다.)

## 모순된 지시를 주면 영상이 멈춥니다

실제로 겪은 조합입니다. 둘 중 하나만 남겨야 합니다.

| 같이 넣으면 안 되는 것 | 결과 |
|---|---|
| "화면이 계속 움직여야 한다" + "오래 움직이는 화면을 만들지 마라" | 말만 하고 화면이 정지 |
| "5~8초마다 컷을 바꿔라" + 13초짜리 장면 목록 | 장면 구간을 무시 |
| 앞에 쓴 화면 지시 + 장면마다 또 쓴 화면 지시 | 둘을 섞어 엉뚱하게 |

강조 모션(팝업·확대)은 **수치·핵심어가 나올 때만**, 배경의 은은한 움직임은 **끊기지 않게** —
이렇게 나눠 써야 의도대로 나옵니다.

## 화면을 꽉 채우기

지정하지 않으면 영상·이미지를 화면 일부에만 놓고 나머지를 단색으로 비웁니다.
프롬프트에 이 세 줄이 필요합니다.

- 모든 장면은 화면 전체를 채운다. 위아래 여백을 만들지 않는다.
- 제목과 자막은 소재 위에 오버레이로 올린다. 소재를 밀어내지 않는다.
- 화면을 나눠야 할 때는 좌우 분할까지만. 아래쪽 절반을 빈 배경으로 두지 않는다.

## 인물

- 국적을 지정하지 않으면 **서양인 모델과 해외 주택 이미지**를 고릅니다.
- 아바타·B롤 인물·배경·화면 속 글자까지 전부 한국으로 못 박아야 합니다.
- 아바타는 전 구간에 두지 않고 **도입과 마무리에 6초씩 두 번** 정도가 자연스러웠습니다.
  레퍼런스 영상들도 아바타 없이 내레이션으로만 갑니다.

## 길이와 분할

- 3분 이하는 한 편으로 나옵니다 (3분 45초까지 나온 적 있음).
- 5분 이상은 나눠서 만들어 이어붙여야 합니다.
- **나눌 때 "지금은 1번째 조각입니다" 같은 말을 프롬프트에 쓰면 안 됩니다.**
  내레이션에 "1부", "2부", "다음 편에서"가 그대로 들어갑니다.
  금지 사항에 회차 표현을 명시해야 합니다.

## 되는 것과 안 되는 것

| 레퍼런스에서 본 요소 | 헤이젠 |
|---|---|
| 딥 네이비 + 오렌지·하늘색 화면 톤 | 가능 (프롬프트에서 색 지정) |
| B롤 위 내레이션, 생활 장면 | 가능 |
| 2D 차트·아이콘·일러스트, 막대 성장·카운트업 | 가능 |
| 챕터 전환의 전체 화면 타이틀 | 가능 |
| 하단 자막 + 중앙 대형 인용문 | 가능 |
| 차트 눈금과 실제 수치의 일치 | 렌더 후 사람이 대조해야 함 |
| 2~4초 하드컷의 일정한 리듬 | 지정해도 편차가 남음 |
| 글리치·와이프 전환 | 불가 — 후편집 필요 |
| 공식 영상·역사 자료 아카이브 | 불가 — 권리 확보한 소스를 직접 삽입 |

## API

- 요금은 **만들어진 영상의 초 단위**로 나갑니다. 아바타가 나온 초가 원가를 좌우합니다.
- 인증은 `X-Api-Key` 헤더입니다.
- **claude.ai 로 띄운 페이지에서는 헤이젠 API를 부를 수 없습니다.**
  브라우저 샌드박스가 외부 호출을 막고, 키를 페이지에 넣으면 누구나 볼 수 있습니다.
  → 키를 가진 작은 프로그램이 PC에서 돌아야 합니다.
- 생성·상태 확인 주소는 계정마다 다를 수 있어 **직접 확인이 필요합니다.**
  이 작업 환경에서는 헤이젠 서버 접속이 막혀 있어 검증하지 못했습니다.

## 시청자에게 통한 방식

- 첫 10~20초는 **고객이 실제로 겪는 장면이나 확인하고 싶은 한 문장**으로 시작합니다.
  회사 연혁이나 기능 목록부터 나열하면 바로 이탈합니다.
- 한 화면에는 이미지·수치·제목 중 **하나만** 주인공으로 둡니다.
- 로고와 안내 문구는 **마지막 구간에만** 노출합니다.
- 업체·공법 비교는 넣지 않습니다.
