# 콘텐츠 보관함

만들어진 결과물이 여기에 쌓입니다. 명령어를 돌리면 자동으로 저장됩니다.

| 폴더 | 무엇이 | 만드는 명령어 |
|---|---|---|
| `블로그/` | 블로그 원고 (복사용 본문 포함) | `/cm-blog` |
| `SNS/` | 카드뉴스 원고, 캡션, 해시태그 | `/cm-sns` |
| `보도자료/` | 언론 배포용 보도자료 | `/cm-press` |
| `세일즈자료/` | 랜딩·제안서·카탈로그·이메일/문자 문안 | `/cm-sales` |

## 파일 이름 규칙

```
YYYY-MM-DD-브랜드-주제.md
예) 2026-08-18-넷폼-공법시공비용.md
```

## 파일 맨 위 표는 지우지 마세요

검수 상태·발행일·발행 URL이 여기 기록됩니다.
`/cm-review` 가 이 표를 읽고 갱신하고, 나중에 성과를 볼 때 기준이 됩니다.

## 발행한 뒤에

파일 맨 위 표의 `발행일` 과 `발행 URL` 을 채워주세요.
나중에 `/cm-keyword` 로 순위를 확인하거나, 어떤 글이 잘 됐는지 볼 때 씁니다.
