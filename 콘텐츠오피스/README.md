# 콘텐츠 오피스

CRM마케팅팀 콘텐츠 업무 7개 부서를 픽셀 사무실로 만든 화면입니다.

| 파일 | 무엇 | 여는 법 |
|---|---|---|
| `AI-콘텐츠오피스.html` | **AI 연결됨.** 부서를 누르면 진짜로 원고가 나옵니다 | 더블클릭 |
| `index.html` | 화면만. AI 없음 | 더블클릭 / 링크 공유용 |

---

## AI 버전 쓰는 법

1. `AI-콘텐츠오피스.html` **더블클릭** — 브라우저가 열립니다
2. 오른쪽 위 **OPENAI KEY** 칸에 `sk-` 로 시작하는 키를 붙여넣습니다
   (기존 생성기에서 쓰시던 그 키입니다. 한 번 넣으면 이 브라우저에 저장됩니다)
3. 부서를 클릭 → 내용을 채우고 → **만들기** 를 누릅니다
4. 결과가 나오면 **복사하기** → 네이버 블로그에 붙여넣기

설치할 것 없습니다. 인터넷만 되면 됩니다.

## 안에 들어 있는 것

`브랜드기준/` 폴더의 내용이 프롬프트로 들어가 있습니다.

- 사용 가능한 실적 목록 — **이 목록에 없는 수치는 `[확인 필요]` 로 비웁니다**
- POUR 금지어·대체표 (신기술→검증된 기술 등)
- 아파트스퀘어 금지어·대체표 (보장→확보, 안전 관리→품질 검토 등)
- 아파트스퀘어 3대 원칙 — 역할 경계 / 확립된 현재형 / 앱으로만 신뢰 증명
- 옥상에는 드론을 쓰지 않는다는 규칙
- 페르소나 7명, 브랜드별 HTML 서식

AI가 글을 쓴 뒤 **금지어를 한 번 더 자동 교정**하고, 무엇을 바꿨는지 목록으로 보여줍니다.
